## 环境变量文件

**`hile start`** 默认不会自动读取 `.env`；需要时用 **`--env-file`**（可重复指定）：

```bash
hile start --dev --env-file .env
hile start --env-file .env --env-file .env.local
```

集成包（如 **TypeORM**、**ioredis**）通常从 **`process.env`** 读取连接参数；本地开发可将变量写入 `.env` 再通过上述选项注入。各变量名见 [@hile/typeorm](/packages/typeorm)、[@hile/ioredis](/packages/ioredis)。

## Registry 工作目录

**`hile registry`** 启动时自动创建 `~/.registry/` 工作目录。YAML 配置文件存放在 `~/.registry/configs/` 下，按 namespace 分文件管理：

```yaml
# ~/.registry/configs/service-a.config.yaml
db:
  host: 10.0.0.2
  port: 3306
```

Registry 监听 `configs/` 目录的文件变化，新增或修改 `*.config.yaml` 文件时自动加载（兼容 vim/vi 保存方式），无需重启。

已连服务可通过 `getEnvVariables()` 远程读取 Registry 的配置：

```typescript
import { Application } from '@hile/micro';

const app = new Application({
  namespace: 'my-service',
  registry: { host: '127.0.0.1', port: 9876 },
});

// 启动后从 Registry 远程读取配置
const config = await app.getEnvVariables(
  { namespace: 'service-a', fields: ['db.host', 'db.port'] },
);
// => { 'service-a': { 'db.host': '10.0.0.2', 'db.port': 3306 } }
```

详见 [@hile/micro](/packages/micro)。

## CLI 管理配置

通过 `hile registry configs` 子命令可直接管理本机 `~/.registry/configs/` 下的 YAML 配置文件，无需手动编辑：

```bash
# 列出所有 namespace
hile registry configs

# 查看配置（YAML 输出）
hile registry configs get my-service

# 查看配置（JSON 输出）
hile registry configs get my-service --json

# 设置配置项（值自动推断类型）
hile registry configs set my-service port=8080
hile registry configs set my-service debug=true
hile registry configs set my-service name=hello

# 删除整个 namespace（需确认）
hile registry configs del my-service

# 删除某个字段（需确认）
hile registry configs del my-service port

# 跳过确认
hile registry configs del my-service -y
```

运行中的 Registry 通过 `fs.watch` 自动感知文件变化，无需重启。

## `package.json` 中的 `hile` 字段

常用字段：**`auto_load_packages`** —— 字符串数组，列出要在启动时 **`import()`** 的包名（用于触发包侧注册逻辑，例如自动注册服务）。

```json
{
  "hile": {
    "auto_load_packages": ["@hile/typeorm", "@hile/ioredis"]
  }
}
```

行为细节与边界见 [@hile/cli](/packages/cli)。
