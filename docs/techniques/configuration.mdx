## 环境变量文件

**`hile start`** 默认不会自动读取 `.env`；需要时用 **`--env-file`**（可重复指定）：

```bash
hile start --dev --env-file .env
hile start --env-file .env --env-file .env.local
```

集成包（如 **TypeORM**、**ioredis**）通常从 **`process.env`** 读取连接参数；本地开发可将变量写入 `.env` 再通过上述选项注入。各变量名见 [@hile/typeorm](/packages/typeorm)、[@hile/ioredis](/packages/ioredis)。

## Registry 工作目录

**`hile registry`** 启动时自动创建 `~/.registry/` 目录，并从 `~/.registry/.env` 加载环境变量：

```bash
# ~/.registry/.env
REGISTRY_PORT=9876
REGISTRY_HOST=192.168.1.100
```

Registry 监听 `.env` 文件变化并自动热加载（兼容 vim/vi 保存方式），无需重启。

已连服务可通过 `getEnvVariables()` 远程读取 Registry 的环境变量：

```typescript
import { Application } from '@hile/micro';

const app = new Application({
  namespace: 'my-service',
  registry: { host: '127.0.0.1', port: 9876 },
});

// 启动后从 Registry 远程读取环境变量
const [dbHost, dbPort] = await app.getEnvVariables('DB_HOST', 'DB_PORT');
```

详见 [@hile/micro](/packages/micro)。

## `package.json` 中的 `hile` 字段

常用字段：**`auto_load_packages`** —— 字符串数组，列出要在启动时 **`import()`** 的包名（用于触发包侧注册逻辑，例如自动注册服务）。

```json
{
  "hile": {
    "auto_load_packages": ["@hile/typeorm", "@hile/ioredis"]
  }
}
```

行为细节与边界见 [@hile/cli](/packages/cli)。
