## @hile/typeorm 是什么？

`@hile/typeorm` 是 TypeORM 集成包，提供两种使用模式：

1. **手动模式** —— `createDataSource()` 直接创建 DataSource
2. **容器模式** —— default export 注册为容器服务，由容器管理生命周期

同时提供 `transaction()` 事务辅助函数。

## 安装

```bash
pnpm add @hile/typeorm
```

还需安装 peer 依赖和数据库驱动：

```bash
pnpm add @hile/core typeorm reflect-metadata
pnpm add mysql2   # MySQL / MariaDB
# 或 pg (PostgreSQL)、sqlite3 (SQLite)、mssql (SQL Server)
```

## 环境变量配置

| 变量 | 说明 | 必填 | 示例 |
|------|------|------|------|
| `TYPEORM_TYPE` | 数据库类型 | 是 | `mysql`、`postgres` |
| `TYPEORM_HOST` | 主机 | 是 | `localhost` |
| `TYPEORM_USERNAME` | 用户名 | 是 | `root` |
| `TYPEORM_PASSWORD` | 密码 | 是 | `password123` |
| `TYPEORM_DATABASE` | 数据库名 | 是 | `my_app` |
| `TYPEORM_PORT` | 端口 | 否 | `3306` |
| `TYPEORM_CHARSET` | 字符集 | 否 | `utf8mb4` |
| `TYPEORM_ENTITY_PREFIX` | 表前缀 | 否 | `app_` |
| `TYPEORM_ENTITIES` | 实体路径 | 是 | `dist/entities/**/*.js` |
| `TYPEORM_SYNCHRONIZE` | 自动同步 | 否 | 字符串 `"true"` 开启 |

### .env 示例

```bash
TYPEORM_TYPE=mysql
TYPEORM_HOST=localhost
TYPEORM_PORT=3306
TYPEORM_USERNAME=root
TYPEORM_PASSWORD=password123
TYPEORM_DATABASE=my_app
TYPEORM_ENTITIES=dist/entities/**/*.js
TYPEORM_SYNCHRONIZE=false
```

### TYPEORM_SYNCHRONIZE

- 值 = `"true"` → 开启自动同步（开发环境）
- 其他情况 → 关闭（生产环境必须关闭）

开发模式下自动开启 SQL 日志（`logging: NODE_ENV === 'development'`）。

## createDataSource —— 手动模式

```typescript
import { createDataSource } from '@hile/typeorm'

// 从环境变量读取
const dataSource = await createDataSource()

// 传入自定义配置
const dataSource = await createDataSource({
  type: 'mysql',
  host: process.env.DB_HOST || 'localhost',
  port: 3306,
  username: 'root',
  password: 'secret',
  database: 'my_app',
  entities: [User, Post],
  synchronize: true,
  logging: true,
})

// 使用完毕后关闭
await dataSource.destroy()
```

## 容器模式（default export）

`@hile/typeorm` 的 default export 是一个已注册的服务：

```typescript
// @hile/typeorm 内部
export default defineService(Symbol.for('@hile/typeorm'), async (shutdown) => {
  const connection = await createDataSource()
  shutdown(() => connection.destroy())
  return connection
})
```

### 自动加载

```json
{ "hile": { "auto_load_packages": ["@hile/typeorm"] } }
```

### 手动加载

```typescript
import { loadService } from '@hile/core'
import typeormService from '@hile/typeorm'

const dataSource = await loadService(typeormService)
```

### 在服务中使用

```typescript
import { loadService } from '@hile/core'
import typeormService from '@hile/typeorm'

const myService = defineService('my-service', async (shutdown) => {
  const dataSource = await loadService(typeormService)
  const users = await dataSource.query('SELECT * FROM users')
  const repo = dataSource.getRepository(User)
  shutdown(() => {})
  return { dataSource, repo }
})
```

## 事务辅助函数

### 基本用法

```typescript
import { transaction } from '@hile/typeorm'

const result = await transaction(dataSource, async (runner, rollback) => {
  await runner.query('INSERT INTO users (name) VALUES (?)', ['Alice'])
  return { success: true }
})
// 自动 commit，返回结果
```

### 失败自动回滚

```typescript
try {
  await transaction(dataSource, async (runner, rollback) => {
    await runner.query('INSERT INTO users (name) VALUES (?)', ['Alice'])
    throw new Error('出错了！')
    // 前面的 INSERT 自动回滚
  })
} catch (e) {
  console.log('事务已回滚')
}
```

### 补偿回调（rollback）

事务失败时，注册的补偿回调在回滚之后按 LIFO 执行：

```typescript
await transaction(dataSource, async (runner, rollback) => {
  await runner.query('INSERT INTO users (name) VALUES (?)', ['Alice'])

  rollback(() => {
    console.log('清除缓存')
    cache.del('user:alice')
  })

  await runner.query('INSERT INTO notifications ...', [1, 'Welcome'])

  rollback(() => {
    console.log('删除通知')
  })

  if (someCondition) throw new Error('出错了！')
  // 回滚后按 LIFO 执行补偿：
  // 1. 删除通知
  // 2. 清除用户缓存

  return 'success'
})
```

### 函数签名

```typescript
function transaction<T>(
  datasource: DataSource,
  callback: (
    runner: QueryRunner,
    rollback: (fn: () => unknown | Promise<unknown>) => number
  ) => Promise<T>
): Promise<T>
```

| 参数 | 说明 |
|------|------|
| `datasource` | TypeORM DataSource 实例 |
| `runner` | QueryRunner，用于在事务中执行查询 |
| `rollback(fn)` | 注册补偿回调，返回当前补偿数组长度 |

## Entity 定义

```typescript
import { Entity, PrimaryGeneratedColumn, Column, CreateDateColumn } from 'typeorm'

@Entity('users')
export class User {
  @PrimaryGeneratedColumn()
  id: number

  @Column({ length: 100 })
  name: string

  @Column({ unique: true })
  email: string

  @CreateDateColumn()
  createdAt: Date
}
```

实体路径配置：

```bash
# 生产（编译后）
TYPEORM_ENTITIES=dist/entities/**/*.js

# 开发（如需要）
TYPEORM_ENTITIES=src/entities/**/*.ts
```

  </Accordion>
  <Accordion title="如何连接多个数据库？">

    ```typescript
    const primaryDb = defineService('db-primary', async (shutdown) => {
      const conn = await createDataSource({ type: 'mysql', database: 'app1' })
      shutdown(() => conn.destroy())
      return conn
    })
    ```
