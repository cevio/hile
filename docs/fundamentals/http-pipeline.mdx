## @hile/http 架构概览

`@hile/http` 建立在两个底层库之上：

- **Koa** —— 提供优雅的中间件洋葱模型
- **find-my-way** —— 高性能 HTTP 路由器（Fastify 同款）

请求管线：

```
客户端请求
    │
    ▼
┌──────────────────────────────────────┐
│ Koa 全局中间件链（按 use() 注册顺序）  │
│  ├─ 中间件 1（请求日志）              │
│  ├─ 中间件 2（CORS）                 │
│  └─ ...                             │
├──────────────────────────────────────┤
│ router.routes()（listen 时注入）      │
├──────────────────────────────────────┤
│ find-my-way 路由匹配                  │
│  ├─ 匹配 → 路由中间件 → 控制器        │
│  │         → 响应插件链 → ctx.body    │
│  └─ 未匹配 → defaultRoute(next())    │
│              → Koa 默认 404          │
└──────────────────────────────────────┘
```

## Http 类

### 创建实例

```typescript
import { Http } from '@hile/http'

const http = new Http({ port: 3000 })
```

### 配置参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `port` | `number` | **必填** | 监听端口 |
| `keys` | `string[]` | 自动生成（2 个随机 32/64 字节密钥） | Koa 签名 cookie 密钥 |
| `ignoreDuplicateSlashes` | `boolean` | `true` | 忽略重复斜杠 |
| `ignoreTrailingSlash` | `boolean` | `true` | 忽略末尾斜杠 |
| `maxParamLength` | `number` | `Infinity` | 路径参数最大长度 |
| `allowUnsafeRegex` | `boolean` | `false` | 允许不安全正则 |
| `caseSensitive` | `boolean` | `true` | 路由区分大小写 |

```typescript
const http = new Http({
  port: 3000,
  keys: ['my-secret-1', 'my-secret-2'],
  ignoreDuplicateSlashes: true,
  ignoreTrailingSlash: true,
  maxParamLength: 100,
  allowUnsafeRegex: false,
  caseSensitive: true,
})
```

### 获取端口

```typescript
console.log(http.port) // 3000
```

## 全局中间件（use）

`http.use(middleware)` 注册标准 Koa 中间件。中间件按注册顺序构成洋葱模型：

```typescript
// 请求日志
http.use(async (ctx, next) => {
  const start = Date.now()
  await next()
  console.log(`${ctx.method} ${ctx.url} - ${Date.now() - start}ms`)
})

// CORS
http.use(async (ctx, next) => {
  ctx.set('Access-Control-Allow-Origin', '*')
  if (ctx.method === 'OPTIONS') { ctx.status = 204; return }
  await next()
})

// use 返回 this，支持链式调用
http.use(mw1).use(mw2).use(mw3)
```

洋葱模型：

```typescript
http.use(async (ctx, next) => {
  console.log('1. 进入 A')
  await next()
  console.log('5. 离开 A')
})
http.use(async (ctx, next) => {
  console.log('2. 进入 B')
  await next()
  console.log('4. 离开 B')
})
http.get('/hello', async (ctx) => {
  console.log('3. 控制器')
  ctx.body = 'Hello'
})
// 输出：1 → 2 → 3 → 4 → 5
```

## 手动路由注册

### 按 HTTP 方法

每个方法返回注销函数：

```typescript
http.get('/users', async (ctx) => { ctx.body = { users: [] } })
http.post('/users', async (ctx) => { ctx.body = { id: 1 } })
http.put('/users/:id', async (ctx) => { ctx.body = { updated: ctx.params.id } })
http.delete('/users/:id', async (ctx) => { ctx.status = 204 })
http.patch('/users/:id', async (ctx) => { ctx.body = { patched: ctx.params.id } })
http.trace('/debug', async (ctx) => { ctx.body = ctx.request })
```

### 通用 route 方法

```typescript
http.route('OPTIONS', '/users', async (ctx) => { ctx.status = 204 })
```

### 路径参数

使用 `:paramName` 语法，通过 `ctx.params` 获取：

```typescript
http.get('/users/:userId/posts/:postId', async (ctx) => {
  ctx.body = { userId: ctx.params.userId, postId: ctx.params.postId }
})
```

### 路由级中间件

```typescript
const auth = async (ctx, next) => {
  if (!ctx.headers.authorization) ctx.throw(401)
  ctx.state.user = { id: 1 }
  await next()
}

http.post('/users', auth, async (ctx) => {
  ctx.body = { message: `Hello, ${ctx.state.user.id}` }
})
```

### 注销路由

```typescript
const off = http.get('/temporary', async (ctx) => { ctx.body = 'temp' })
off()  // 移除路由
```

## find-my-way 特性

`@hile/http` 内部使用 find-my-way 作为路由器，支持：

**通配符：**

```typescript
http.get('/files/*', async (ctx) => {
  ctx.body = { path: ctx.params['*'] }
})
```

**正则参数：**

```typescript
http.get('/users/:id(\\d+)', async (ctx) => {
  ctx.body = { id: ctx.params.id }
})
// GET /users/123 → 匹配
// GET /users/abc → 不匹配
```

## 控制器（defineController）

### 重载 1：仅 method + 处理函数

```typescript
import { defineController } from '@hile/http'

export default defineController('GET', async (ctx) => {
  return { message: 'Hello!' }
})
```

### 重载 2：method + 前置中间件 + 处理函数

```typescript
const auth = async (ctx, next) => {
  if (!ctx.headers.authorization) ctx.throw(401)
  await next()
}

export default defineController('POST', [auth], async (ctx) => {
  return { success: true }
})
```

### 重载 3：metadata + 处理函数（推荐）

```typescript
import { z } from 'zod'
import { defineController, createControllerMetadata } from '@hile/http'

const meta = createControllerMetadata({
  method: 'GET',
  schema: {
    query: z.object({
      page: z.coerce.number().default(1),
      limit: z.coerce.number().max(100).default(20),
    }),
  },
})

export default defineController(meta, async (ctx) => {
  return { page: ctx.query.page }
})
```

## Zod 校验

当 `createControllerMetadata` 中提供 `schema` 时，控制器中间件会在处理函数前自动校验。校验失败自动 `ctx.throw(400, error.message)`。

**重要**：校验不会改写 `ctx.query`/`ctx.params`/`ctx.request.body` 的值。校验的目的只是验证合法性，不是类型转换。

### query 校验

```typescript
createControllerMetadata({
  method: 'GET',
  schema: { query: z.object({ page: z.coerce.number().min(1).default(1) }) },
})
```

### params 校验

```typescript
createControllerMetadata({
  method: 'GET',
  schema: { params: z.object({ id: z.coerce.number().positive() }) },
})
```

### body 校验

```typescript
createControllerMetadata({
  method: 'POST',
  schema: { body: z.object({ name: z.string().min(1), email: z.string().email() }) },
})
```

### 同时校验多项

```typescript
createControllerMetadata({
  method: 'PUT',
  schema: {
    params: z.object({ id: z.coerce.number() }),
    body: z.object({ name: z.string().optional(), email: z.string().email().optional() }),
    query: z.object({ validate: z.coerce.boolean().optional() }),
  },
})
```

## 响应插件链（defineResponsePlugin）

全局注册插件，在控制器返回值写入 `ctx.body` 前对结果进行变换：

```typescript
import { defineResponsePlugin } from '@hile/http'

// 统一响应格式
defineResponsePlugin(async (ctx, result, next) => {
  return await next({
    code: 0,
    data: result,
    timestamp: Date.now(),
  })
})

// 错误格式包装
defineResponsePlugin(async (ctx, result, next) => {
  if (result?.error) {
    return await next({ code: -1, message: result.error })
  }
  return await next(result)
})
```

插件签名：`(ctx: Context, result: any, next: (r: any) => Promise<void>) => Promise<any>`

执行流程：

```
控制器返回值
  → 插件 1（next(transformed1)）
    → 插件 2（next(transformed2)）
      → ... → 最终值写入 ctx.body
```

注意：
- 插件是**全局**的，不区分 Http 实例
- 插件按注册顺序执行
- 控制器返回 `undefined` 时不触发插件链

## 文件系统路由加载

### load 方法

```typescript
const http = new Http({ port: 3000 })

const unload = await http.load('./controllers', {
  suffix: 'controller',     // *.controller.ts
  defaultSuffix: '/index',  // index.controller → /
  prefix: '/api',           // 路由前缀
  conflict: 'error',        // 冲突策略
})
unload()  // 移除所有通过 load 注册的路由
```

### 文件命名映射

```
controllers/
├── hello.controller.ts           → /api/hello
├── users.controller.ts           → /api/users
├── users/
│   ├── index.controller.ts       → /api/users（index → 父路径）
│   ├── [id].controller.ts        → /api/users/:id
│   └── [id]/posts.controller.ts  → /api/users/:id/posts
```

转换规则：
1. 去掉 `.{suffix}.{ext}` 后缀
2. `[param]` → `:param`
3. 文件名 = `defaultSuffix` 时去掉该段
4. 反斜杠 → 正斜杠，合并连续斜杠
5. 添加 `prefix`

### 文件内容约定

每个文件 `export default` 一个 `defineController(...)` 的返回值（单个或数组）：

```typescript
// 单个
export default defineController('GET', async (ctx) => { return [] })

// 多个方法同文件
export default [
  defineController('GET', async (ctx) => { return [] }),
  defineController('POST', async (ctx) => { return { created: true } }),
]
```

### 路由冲突策略

| 策略 | 行为 |
|------|------|
| `'error'`（默认） | 抛出 `route conflict` 错误 |
| `'warn'` | 打印警告，保留先注册的路由 |
| `'override'` | 用新路由覆盖旧路由 |

## 启动和关闭

### listen 方法

```typescript
const http = new Http({ port: 3000 })

// 启动
const close = await http.listen()
// 内部：注入 router.routes() → createServer → server.listen(port)

// 带回调
const close = await http.listen((server) => {
  console.log(`Server running on port ${http.port}`)
})

// 关闭
close()
```

**listen 必须在所有路由注册完成后调用。**

### 完整生命周期

```typescript
import { Http } from '@hile/http'
import { defineService, loadService, container } from '@hile/core'

const httpService = defineService('http-server', async (shutdown) => {
  const http = new Http({ port: 3000 })

  http.use(async (ctx, next) => {
    const start = Date.now()
    await next()
    console.log(`${ctx.status} ${ctx.method} ${ctx.url} - ${Date.now() - start}ms`)
  })

  http.get('/ping', async (ctx) => { ctx.body = 'pong' })

  const close = await http.listen()
  shutdown(() => { console.log('关闭 HTTP'); close() })
  return http
})

await loadService(httpService)
// ... 运行 ...
await container.shutdown()
```
