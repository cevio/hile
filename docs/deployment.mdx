# 生产部署

## 开发模式 vs 生产模式

| 特性 | 开发 (`hile start --dev`) | 生产 (`hile start`) |
|------|--------------------------|---------------------|
| `NODE_ENV` | `development` | `production` |
| TypeScript | tsx 直接执行 `src/` 中的 TS | 运行 `dist/` 中编译后的 JS |
| 容器事件日志 | 彩色输出 | 不输出 |
| TypeORM 日志 | 开启 | 关闭 |
| 文件扫描 | `src/**/*.boot.{ts,js}` | `dist/**/*.boot.{ts,js}` |

## 第一步：构建 TypeScript

```bash
pnpm run build   # 等同于 tsc -b
```

构建后检查 `dist/` 目录：

```bash
ls dist/
# controllers/  services/  models/
ls dist/services/
# *.boot.js  ← boot 文件已编译
```

<Warning>
如果 `dist/` 中没有 boot 文件，CLI 在生产模式下找不到任何服务。请检查 `tsconfig.json` 的 `include` 配置。
</Warning>

### package.json 脚本配置

```json
{
  "scripts": {
    "dev": "hile start --dev",
    "build": "tsc -b",
    "start": "hile start",
    "clean": "rm -rf dist"
  }
}
```

## 第二步：环境变量配置

### 核心变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `NODE_ENV` | 运行模式。CLI 生产模式自动设为 `production` | `production` |

### TypeORM 变量

| 变量 | 生产建议 |
|------|----------|
| `TYPEORM_HOST` | 生产数据库地址 |
| `TYPEORM_PASSWORD` | 从密钥管理服务获取 |
| `TYPEORM_ENTITIES` | `dist/entities/**/*.js` |
| `TYPEORM_SYNCHRONIZE` | **必须为 `false`** |

### Redis 变量

| 变量 | 说明 |
|------|------|
| `REDIS_HOST` | Redis 服务地址 |
| `REDIS_PASSWORD` | 从密钥管理服务获取 |

### Micro 变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `MICRO_HEARTBEAT_INTERVAL` | `10000` | 心跳间隔（ms） |
| `MICRO_HEARTBEAT_TIMEOUT` | `20000` | 心跳超时（ms） |
| `MICRO_HEARTBEAT_CHECK_INTERVAL` | `5000` | 检查间隔（ms） |
| `REGISTRY_PORT` | `9876` | Registry 端口 |

### .env 文件

```bash
# .env.prod
TYPEORM_TYPE=mysql
TYPEORM_HOST=db.example.com
TYPEORM_PORT=3306
TYPEORM_USERNAME=app_user
TYPEORM_PASSWORD=s3cret!
TYPEORM_DATABASE=myapp_prod
TYPEORM_ENTITIES=dist/entities/**/*.js
TYPEORM_SYNCHRONIZE=false

REDIS_HOST=redis.example.com
REDIS_PORT=6379
REDIS_PASSWORD=s3cret!

LOG_LEVEL=info
```

### --env-file 加载

```bash
# 单个文件
hile start --env-file .env.prod

# 多个文件（先加载优先）
hile start -e .env -e .env.prod
```

使用 Node.js 原生 `process.loadEnvFile()`。**先加载的文件优先级更高**。

## 第三步：生产启动

```bash
# 最简
NODE_ENV=production hile start

# 带 env 文件
hile start -e .env.prod

# 通过 pnpm
pnpm run start
```

### Node.js 优化

```bash
# 内存限制
NODE_OPTIONS="--max-old-space-size=512" hile start

# Source Map 支持（tsconfig.json 中需开启 sourceMap）
NODE_OPTIONS="--enable-source-maps" hile start
```

## 第四步：优雅关闭

Hile 通过 `async-exit-hook` 捕获 SIGINT/SIGTERM，自动调用 `container.shutdown()`：

```
收到信号 → container.shutdown()
  → emit('container:shutdown:start')
  → 按 LIFO 顺序遍历服务
    → 每个服务的 teardown 按 LIFO 执行
  → 循环检查（捕获晚注册 teardown）
  → emit('container:shutdown:done')
  → 进程退出
```

每个服务应在工厂函数中注册关闭回调：

```typescript
export default defineService('http-server', async (shutdown) => {
  const http = new Http({ port: 3000 })
  const close = await http.listen()
  shutdown(close)  // 注册关闭
  return http
})
```

## 第五步：Docker 部署

### 多阶段构建 Dockerfile

```dockerfile
# 构建阶段
FROM node:22-alpine AS builder
WORKDIR /app
RUN corepack enable && corepack prepare pnpm@latest --activate
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile
COPY tsconfig.json ./
COPY src/ ./src/
RUN pnpm run build

# 生产阶段
FROM node:22-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
RUN corepack enable && corepack prepare pnpm@latest --activate
COPY package.json pnpm-lock.yaml ./
RUN pnpm install --frozen-lockfile --prod
COPY --from=builder /app/dist ./dist
EXPOSE 3000
HEALTHCHECK --interval=30s --timeout=3s --start-period=10s --retries=3 \
  CMD wget --no-verbose --tries=1 --spider http://localhost:3000/ || exit 1
USER node
CMD ["node", "/app/node_modules/.bin/hile", "start"]
```

### .dockerignore

```
node_modules
dist
.next
.git
.env
.env.*
*.md
coverage
```

### 构建和运行

```bash
docker build -t my-hile-app:latest .

docker run -d --name my-app -p 3000:3000 \
  -e TYPEORM_HOST=db.example.com \
  -e TYPEORM_PASSWORD=s3cret! \
  my-hile-app:latest
```

### Docker Compose

```yaml
services:
  app:
    build: .
    ports: ["3000:3000"]
    environment:
      - NODE_ENV=production
      - TYPEORM_HOST=db
      - TYPEORM_PASSWORD=app_password
      - REDIS_HOST=redis
    depends_on:
      db: { condition: service_healthy }
      redis: { condition: service_healthy }
    restart: unless-stopped

  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: myapp
    volumes: [db_data:/var/lib/mysql]
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]

  redis:
    image: redis:7-alpine
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]

volumes:
  db_data:
```

## 第六步：进程管理

### PM2

```javascript
// ecosystem.config.cjs
module.exports = {
  apps: [{
    name: 'my-hile-app',
    script: 'hile',
    args: 'start --env-file .env.prod',
    instances: 1,
    exec_mode: 'fork',
    autorestart: true,
    max_memory_restart: '512M',
    kill_timeout: 30000,     // 等待优雅关闭
    listen_timeout: 15000,   // 等待启动
    env: { NODE_ENV: 'production' },
  }],
}
```

常用命令：

```bash
pm2 start ecosystem.config.cjs
pm2 status
pm2 logs my-hile-app
pm2 restart my-hile-app
pm2 stop my-hile-app
pm2 save
```

### systemd

```ini
# /etc/systemd/system/hile-app.service
[Unit]
Description=Hile Application
After=network.target

[Service]
Type=simple
User=deploy
WorkingDirectory=/opt/my-hile-app
ExecStart=/usr/local/bin/hile start --env-file .env.prod
Restart=always
RestartSec=10
TimeoutStopSec=30
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

### Kubernetes

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-hile-app
spec:
  replicas: 3
  selector:
    matchLabels: { app: my-hile-app }
  template:
    metadata:
      labels: { app: my-hile-app }
    spec:
      containers:
      - name: app
        image: my-hile-app:latest
        ports: [{ containerPort: 3000 }]
        env:
        - name: NODE_ENV
          value: "production"
        - name: TYPEORM_PASSWORD
          valueFrom:
            secretKeyRef:
              name: db-secret
              key: password
        livenessProbe:
          httpGet: { path: /, port: 3000 }
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet: { path: /, port: 3000 }
          initialDelaySeconds: 5
          periodSeconds: 5
        lifecycle:
          preStop:
            exec:
              command: ["sleep", "5"]
        resources:
          requests: { memory: "256Mi", cpu: "250m" }
          limits: { memory: "512Mi", cpu: "500m" }
      terminationGracePeriodSeconds: 60
```

## 健康检查

添加健康检查端点：

```typescript
// src/controllers/health.controller.ts
import { defineController } from '@hile/http'

export default defineController('GET', async (ctx) => {
  return { status: 'ok', uptime: process.uptime(), timestamp: Date.now() }
})
```

使用 `@hile/micro` 的 Application 会自动注册 `/-/health` 端点。

## 常见问题

<Accordion title="生产模式看不到 [hile] 日志？">
这是正常的。生产模式不输出容器事件日志。如需日志可手动订阅：

```typescript
import { container } from '@hile/core'
container.on((event) => { /* 自定义日志处理 */ })
```

</Accordion>

<Accordion title="Error: Cannot find module in dist/">
检查 `tsconfig.json`：确保 `include: ["src"]`、`rootDir: "./src"`、`outDir: "./dist"`。

```bash
find dist -name "*.js" -type f  # 确认文件已生成
```
</Accordion>

<Accordion title="生产模式请求返回 404">
CLI 在生产模式扫描 `dist/`。确保 `http.load()` 路径正确。建议根据 NODE_ENV 动态设置：

```typescript
const isDev = process.env.NODE_ENV === 'development'
const dir = isDev ? './src/controllers' : './dist/controllers'
await http.load(dir, { suffix: 'controller' })
```

</Accordion>

<Accordion title="Docker 容器启动后立即退出">
可能原因：端口冲突、数据库连接失败、环境变量缺失。

```bash
docker logs <container-id>
```
</Accordion>
