## 使用方式

<Steps>
  <Step title="创建项目">
    ```bash
    npx create-hile-http-next create my-app
    ```
  </Step>
  <Step title="安装依赖">
    ```bash
    cd my-app
    pnpm install
    ```
  </Step>
  <Step title="启动开发">
    ```bash
    pnpm run dev
    ```
  </Step>
</Steps>

也可以全局安装后使用：

```bash
npm i -g create-hile-http-next
create-hile-http-next create my-app
```

## 可用命令

| 命令 | 说明 |
|------|------|
| `pnpm run dev` | 构建 Next.js 并以开发模式启动 |
| `pnpm run build` | TypeScript + Next.js 生产构建 |
| `pnpm run start` | 生产模式启动 |
