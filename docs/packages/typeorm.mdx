## 安装

```bash
pnpm add @hile/typeorm
```

同时确保安装了 peer 依赖：

```bash
pnpm add @hile/core typeorm
```

还需要安装数据库驱动（按你使用的数据库选择）：

```bash
# MySQL
pnpm add mysql2

# PostgreSQL
pnpm add pg

# SQLite
pnpm add better-sqlite3
```

---

## 它做了什么？

`@hile/typeorm` 将 TypeORM 的 `DataSource` 封装为 Hile 服务：

1. 从环境变量读取数据库配置
2. 创建 `DataSource` 并调用 `initialize()`
3. 注册 `shutdown(() => connection.destroy())` — 进程退出时自动关闭连接
4. 返回初始化后的 `DataSource` 实例

你只需要配置环境变量，然后 `loadService` 即可获得可用的数据库连接。

## 快速开始

### 第一步：配置环境变量

创建 `.env` 文件：

```env
TYPEORM_TYPE=mysql
TYPEORM_HOST=localhost
TYPEORM_PORT=3306
TYPEORM_USERNAME=root
TYPEORM_PASSWORD=secret
TYPEORM_DATABASE=myapp
TYPEORM_CHARSET=utf8mb4
TYPEORM_ENTITY_PREFIX=app_
TYPEORM_ENTITIES=dist/entities/*.js
# 本地开发可开启自动建表；生产请省略或设为 false，改用 migration
TYPEORM_SYNCHRONIZE=true
```

### 第二步：加载服务

```typescript
import { loadService } from '@hile/core'
import typeormService from '@hile/typeorm'

const ds = await loadService(typeormService)

// 现在可以使用 TypeORM 的全部 API
const users = await ds.query('SELECT * FROM users')
const repo = ds.getRepository(UserEntity)
const manager = ds.manager
```

### 第三步：在控制器中使用

```typescript
// src/controllers/users/index.controller.ts
import { defineController } from '@hile/http'
import { loadService } from '@hile/core'
import typeormService from '@hile/typeorm'

export default defineController('GET', async (ctx) => {
  const ds = await loadService(typeormService)
  const users = await ds.query('SELECT id, name, email FROM users LIMIT 20')
  return { users }
})
```

## 环境变量详解

| 变量 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `TYPEORM_TYPE` | `string` | 是 | 数据库类型：`mysql`、`postgres`、`sqlite`、`mariadb` 等 |
| `TYPEORM_HOST` | `string` | 是 | 数据库主机地址 |
| `TYPEORM_PORT` | `string` | 是 | 数据库端口（会自动转为 number） |
| `TYPEORM_USERNAME` | `string` | 是 | 用户名 |
| `TYPEORM_PASSWORD` | `string` | 是 | 密码 |
| `TYPEORM_DATABASE` | `string` | 是 | 数据库名 |
| `TYPEORM_CHARSET` | `string` | 否 | 字符集（如 `utf8mb4`） |
| `TYPEORM_ENTITY_PREFIX` | `string` | 否 | 表名前缀（如 `app_`） |
| `TYPEORM_ENTITIES` | `string` | 否 | 实体文件路径（glob 格式，如 `dist/entities/*.js`） |
| `TYPEORM_SYNCHRONIZE` | `string` | 否 | 仅当值为 `true` 时启用 `synchronize`；未设置或其他值均为关闭 |

### 自动行为

| 特性 | 说明 |
|------|------|
| `synchronize` | 仅当 `TYPEORM_SYNCHRONIZE=true` 时为 `true`（自动同步表结构），否则为 `false` |
| `logging` | `NODE_ENV === 'development'` 时为 `true`（输出 SQL 日志） |
| `entities` | 未配置 `TYPEORM_ENTITIES` 时为空数组 |
| `shutdown` | 进程退出时自动调用 `connection.destroy()` |

<Warning>
  开启 `synchronize` 会自动修改数据库表结构以匹配实体定义。务必避免在生产环境设置 `TYPEORM_SYNCHRONIZE=true`；需要可控变更时请使用 TypeORM 的 migration。
</Warning>

## 事务辅助

`transaction` 函数提供了一种安全的事务执行方式，支持失败时的补偿回调。

### 基本用法

```typescript
import { loadService } from '@hile/core'
import typeormService, { transaction } from '@hile/typeorm'

const ds = await loadService(typeormService)

const result = await transaction(ds, async (runner, rollback) => {
  // runner 是 TypeORM 的 QueryRunner，已开启事务

  // 执行数据库操作
  await runner.query('INSERT INTO users (name) VALUES (?)', ['Alice'])
  await runner.query('INSERT INTO logs (action) VALUES (?)', ['create_user'])

  return { success: true }
})

// result = { success: true }
```

### 带补偿回调

当事务中还涉及外部操作（如发邮件、调用第三方 API）时，可以注册补偿回调：

```typescript
const result = await transaction(ds, async (runner, rollback) => {
  // 1. 数据库操作
  await runner.query('INSERT INTO orders (amount) VALUES (?)', [100])

  // 2. 调用支付 API
  const paymentId = await paymentApi.charge(100)

  // 注册补偿：如果后续步骤失败，退款
  rollback(async () => {
    await paymentApi.refund(paymentId)
    console.log(`已退款: ${paymentId}`)
  })

  // 3. 发送通知
  await notificationApi.send('订单创建成功')

  // 注册补偿：如果后续步骤失败，撤回通知
  rollback(async () => {
    await notificationApi.revoke()
  })

  return { orderId: 1, paymentId }
})
```

### 失败时的行为

```
事务操作抛出异常
    │
    ▼
① runner.rollbackTransaction()     ← TypeORM 回滚数据库事务
    │
    ▼
② 按 LIFO 顺序执行 rollback 回调    ← 补偿外部操作
    │  ├── 撤回通知
    │  └── 退款
    │  ⚠ 单个回调抛错会中断后续回调
    │
    ▼
③ runner.release()                  ← 释放 QueryRunner
    │
    ▼
④ throw 原始错误                    ← 将原始错误抛给调用者
```

补偿回调的规则：

| 规则 | 说明 |
|------|------|
| LIFO 顺序 | 后注册的先执行 |
| 支持异步 | 回调可以是 `async` 函数 |
| 错误中断 | 如果某个补偿回调抛错，后续回调不会执行，该错误会替换原始异常 |
| 只在失败时执行 | 事务成功提交后不会执行补偿回调 |

## 与 @hile/cli 集成

方式一：通过 `package.json` 自动加载：

```json
{
  "hile": {
    "auto_load_packages": ["@hile/typeorm"]
  }
}
```

方式二：在 boot 文件中手动加载：

```typescript
// src/services/database.boot.ts
import { loadService } from '@hile/core'
import typeormService from '@hile/typeorm'

import { defineService } from '@hile/core'

export default defineService('database.boot', async () => {
  const ds = await loadService(typeormService)
  console.log(`数据库已连接: ${ds.options.database}`)
  return ds
})
```

## 在服务中使用

```typescript
// src/services/order.service.ts
import { defineService, loadService } from '@hile/core'
import typeormService, { transaction } from '@hile/typeorm'

export const orderService = defineService('order', async () => {
  return {
    async createOrder(userId: number, amount: number) {
      const ds = await loadService(typeormService)

      return await transaction(ds, async (runner, rollback) => {
        const result = await runner.query(
          'INSERT INTO orders (user_id, amount, status) VALUES (?, ?, ?)',
          [userId, amount, 'pending']
        )

        rollback(async () => {
          await runner.query('DELETE FROM orders WHERE id = ?', [result.insertId])
        })

        return { orderId: result.insertId }
      })
    },

    async getOrders(userId: number) {
      const ds = await loadService(typeormService)
      return ds.query('SELECT * FROM orders WHERE user_id = ?', [userId])
    }
  }
})
```

## API 参考

| 导出 | 类型 | 说明 |
|------|------|------|
| 默认导出 | `ServiceRegisterProps<DataSource>` | 服务化的 TypeORM DataSource |
| `transaction(ds, callback)` | `function` | 事务执行函数 |

### transaction 签名

```typescript
function transaction<T>(
  datasource: DataSource,
  callback: (
    runner: QueryRunner,
    rollback: (fn: () => unknown | Promise<unknown>) => number
  ) => Promise<T>
): Promise<T>
```

| 参数 | 说明 |
|------|------|
| `datasource` | TypeORM DataSource 实例 |
| `callback` | 事务回调，接收 `runner`（QueryRunner）和 `rollback`（补偿注册函数） |
| 返回值 | 事务成功时返回 callback 的返回值 |
