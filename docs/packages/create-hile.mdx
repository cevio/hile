## 概述

`create-hile` 是一个项目脚手架 CLI 工具。创建时**交互选择内置模板**，将模板目录完整复制到目标路径，并把 `package.json` 的 `name` 改为项目名。部分模板在仓库内用 **`_env`、`_env.prod`、`_gitignore`** 命名（避免点文件在发布链路中被忽略）；复制到目标目录后会**自动重命名**为 **`.env`、`.env.prod`、`.gitignore`**。

---

## 使用方式

### 方式一：npx（推荐）

无需安装，直接运行：

```bash
npx create-hile create my-app
```

### 方式二：全局安装

```bash
npm i -g create-hile
create-hile create my-app
```

---

## 创建流程

<Steps>
  <Step title="运行命令">
    ```bash
    npx create-hile create my-app
    ```

    脚手架会执行以下操作：

    1. 检查 `my-app` 目录是否已存在（如存在则报错）
    2. 交互选择**内置模板**
    3. 创建目录并从所选模板复制所有文件到目标目录
    4. 若模板中存在 `_env` / `_env.prod` / `_gitignore`，则重命名为 `.env` / `.env.prod` / `.gitignore`
    5. 将 `package.json` 的 `name` 字段改为 `my-app`
    6. 可选：是否立即安装依赖（支持 pnpm / yarn / npm）
    7. 输出后续操作提示
  </Step>
  <Step title="安装依赖">
    如果上一步未安装依赖：
    ```bash
    cd my-app
    pnpm install
    ```
  </Step>
  <Step title="启动开发">
    ```bash
    pnpm run dev
    ```
  </Step>
</Steps>

## 内置模板

| 目录名 | 说明 |
|--------|------|
| `default` | 默认 Hile + HTTP，无 Next.js |
| `next` | Next.js + `@hile/http-next` 全栈 |
| `micro-http` | `@hile/micro` + HTTP（与 Registry 等集成） |
| `micro` | 独立 Micro 服务骨架 |
| `micro-http-next` | Next.js + Micro + HTTP 组合 |

---

## CLI 命令参考

```bash
create-hile create <project-name>
```

| 参数 | 说明 |
|------|------|
| `project-name` | 项目名称，也是目标目录名和 `package.json` 的 `name` |

```bash
create-hile -V    # 查看版本
create-hile -h    # 查看帮助
```

<Warning>如果目标目录已存在，命令会报错 `目录 xxx 已存在`。</Warning>
