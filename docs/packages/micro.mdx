## 安装

```bash
pnpm add @hile/micro
```

依赖 `@hile/message-loader`、`@hile/message-ws`、`@hile/message-modem`、`ws`。

## 概述

`@hile/micro` 是基于 WebSocket 的服务通信框架。核心抽象是每个节点都是一个 **Server**，节点间通过 WebSocket 互联，由 **Registry** 维护全局服务拓扑。

### 类层次

```
MessageModem                   请求/响应协议抽象
  └── MessageWs                WebSocket 传输层
        └── Client             远端连接代理 + 心跳

MessageLoader                  路由注册与分发
  └── Server                   WebSocket 服务端（监听 + 连接管理）
        ├── Registry           注册中心（服务拓扑 + 发布订阅）
        └── Application        应用服务（注册发现 + 熔断重试）
```

### 角色

| 类 | 职责 |
|------|------|
| **Server** | WebSocket 监听、连接管理、出站连接。创建 `Client` 实例 |
| **Registry** | 注册中心。维护 namespace → 实例列表，提供服务发现和 topic 发布订阅 |
| **Application** | 应用服务。连接 Registry，提供服务发现、熔断、重试、发布订阅 |
| **Client** | 远端连接的代理。提供 `request()` / `push()` / `stream()` 接口 + 心跳保活 |

## Server

`Server` 是所有服务节点的基类，封装 WebSocket 监听和连接管理。

### 构造

```typescript
import { Server } from '@hile/micro';

const server = new Server('my-service', {
  advertiseHost: '127.0.0.1', // 出站连接时宣告给对端的地址
});
```

- **namespace** — 本服务的标识，出站连接时附加到 URL 路径
- **advertiseHost** — 宣告地址。缺省使用 `getLocalIPv4()` 自动获取；获取失败时构造抛错

### listen

启动 WebSocket 监听：

```typescript
const teardown = await server.listen(port);
// server.port → 实际端口
// server.host  → 宣告地址
// server.clients → Map<"host:port", Client>
```

返回 `teardown` 函数，调用后关闭所有连接并停止监听：

```typescript
await teardown(); // 关闭所有 Client + WebSocketServer
```

### 出站连接

```typescript
await server.setPort(localPort); // 先设置本地端口（构造 URL 用）
const client = await server.connect('10.0.0.2', 9000);
```

`connect()` 建立 WebSocket 连接，URL 格式：

```
ws://{host}:{port}/{advertiseHost}/{localPort}/{namespace}
```

连接成功后返回 `Client` 实例，自动注册到 `server.clients`。同一 `host:port` 的旧连接会被替换并关闭。

### 入站连接

当远端通过 `connect()` 连接本机时，Server 自动创建 `Client` 并加入 `clients` 字典，同时通过 `events` 发射事件：

```typescript
server.events.on('connect', (client, extras) => {});
server.events.on('disconnect', (client, extras) => {});
```

### HTTP 服务器集成

```typescript
// 将 WebSocket 升级逻辑挂载到已有 HTTP 服务
server.handleUpgrade(req, socket, head);
```

## Registry

`Registry` 是注册中心，管理服务拓扑和发布订阅。扩展自 `Server`，namespace 固定为 `'registry'`。

### 构造与启动

```typescript
import { Registry } from '@hile/micro';

const registry = new Registry({ advertiseHost: '127.0.0.1' });
const teardown = await registry.listen(9000);
```

`listen(port)` 还会读取环境变量 `REGISTRY_PORT` 作为兜底端口。启动后自动创建 `~/.registry/` 工作目录。

### 服务发现

Registry 根据 WebSocket 连接路径中的 namespace 自动注册服务。连接时解析 URL 路径 `/{callerHost}/{callerPort}/{namespace}`，将 `{callerHost}:{callerPort}` 加入 `namespaces[namespace]`。

`/-/find` — 按 namespace 查询可用实例：

```typescript
// 请求
{ namespace: 'payments', exclude?: ['10.0.0.1:9100'] }

// 响应（随机选一）
{ host: '10.0.0.2', port: 9100 }
```

### Topic 发布订阅

Registry 内置 topic 系统，支持实时推送：

| 路由 | 方向 | 说明 |
|------|------|------|
| `/-/declare` | Publisher → Registry | 声明 topic 并发布初始数据 |
| `/-/undeclare` | Publisher → Registry | 取消声明 topic |
| `/-/subscribe` | Subscriber → Registry | 订阅 topic，返回当前数据 |
| `/-/unsubscribe` | Subscriber → Registry | 取消订阅 |
| `/-/topic/update` | 任意 → Registry | 推送 topic 更新（转发给所有订阅者） |

Publisher 更新数据后，Registry 自动将新数据推送给所有订阅者。

### 配置文件监听

Registry 监听 `~/.registry/configs/` 目录下的 `*.config.yaml` 文件：

```yaml
# ~/.registry/configs/my-service.config.yaml
db:
  host: localhost
  port: 5432
debug: true
```

- 启动时批量加载已有配置文件
- 通过 `fs.watch` 监听文件变更，增删改自动同步
- 每个配置项作为 topic 发布，路径为 `registry:{namespace}/{key}`

## Application

`Application` 是应用服务的核心类，连接 Registry 实现服务发现、熔断重试、发布订阅。

### 构造

```typescript
import { Application } from '@hile/micro';

const app = new Application({
  namespace: 'my-service',                    // 本服务 namespace
  registry: { host: '127.0.0.1', port: 9000 },// Registry 地址
  advertiseHost: '127.0.0.1',                 // 宣告地址
  registryLookupTimeoutMs: 10_000,            // /-/find 超时，默认 10000
  requestTimeoutMs: 30_000,                   // 单次请求超时，默认 30000
});
```

### listen

```typescript
const teardown = await app.listen(port);
```

- 启动 WebSocket 监听
- **连接 Registry**（失败时整个 `listen` 抛错，不会启动成功但无法工作的状态）
- 返回 teardown 函数，调用后关闭所有连接并停止重连

### 服务发现

```typescript
const client = await app.get('payments');
```

- 首次查询通过 Registry 的 `/-/find` 获取实例地址
- 成功后建立 WebSocket 直连并缓存结果（namespace → Client）
- 缓存断开时自动清理，下次 `get()` 重新发现
- 支持换 peer：通过 `exclude` 参数排除已知故障节点

**缓存降级**：Registry 不可达时，若之前有已建立且仍在线的连接，自动降级使用缓存。

### 路由注册（Provider 侧）

```typescript
const unregister = app.register('/charge', async ({ data, params, client }) => {
  // data   — 请求数据
  // params — URL 路径参数
  // client — 来源 Client（由 @hile/micro 注入）
  return { charged: true, amount: data.amount };
});

// 注销路由
unregister();
```

### call — 一站式请求（Consumer 侧）

```typescript
const result = await app.call('payments', '/charge', { amount: 100 });
// → { charged: true, amount: 100 }
```

`call()` 封装了完整流程：`get()` 发现 → `request()` 调用 → 熔断 → 重试：

```typescript
// 超时 5 秒，失败重试 3 次
await app.call('payments', '/charge', { amount: 100 }, {
  timeout: 5000,
  retries: 3,
});

// 超时 1 秒，不重试
await app.call('payments', '/charge', { amount: 100 }, {
  timeout: 1000,
  retries: 0,
});
```

### 熔断器

`call()` 在每次调用失败后自动记录故障，排除该 peer 30 秒：

| 场景 | 行为 |
|------|------|
| 调用 peer A 失败 | A 加入熔断名单（30s 冷却） |
| 再次 `call` | 熔断名单通过 `exclude` 传给 Registry，返回其他 peer |
| 所有 peer 都被排除 | 重置熔断名单，允许重试所有 peer |
| 调用成功 | 该 peer 从熔断名单中移除 |

### 流式调用

```typescript
const stream = await app.stream('payments', '/stream-data', { query: 'SELECT ...' });
for await (const chunk of stream) {
  console.log(chunk);
}
```

Provider 侧使用 `async function*` 注册流式路由：

```typescript
app.register('/stream-data', async function* ({ data }) {
  for (const item of fetchData(data.query)) {
    yield item;
  }
});
```

### 健康检查

每个 `Application` 自动注册 `/-/health`：

```typescript
const health = await app.dispatch('/-/health', {});
// { status: 'ok', registry: true, uptime: 123.45, namespaces: ['payments'] }
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | `'ok'` | 固定值 |
| `registry` | `boolean` | Registry 连接状态 |
| `uptime` | `number` | 进程启动时长（秒） |
| `namespaces` | `string[]` | 本地已缓存的 namespace 列表 |

### Topic 发布订阅

**发布：**

```typescript
const ref = await app.publish('config/feature-flag', { enabled: true });

// 更新数据（自动推送给所有订阅者）
await ref.update({ enabled: false });

// 取消发布
await ref.unpublish();
```

**订阅：**

```typescript
const unsubscribe = await app.subscribe('config/feature-flag', (data) => {
  console.log('feature flag updated:', data);
  // → { enabled: true }
});
// subscribe 回调会立即收到当前数据
```

- 对同一 topic 重复 `subscribe` 是幂等的（第二次只返回 unsubscribe 函数）
- Registry 故障重连后自动重新订阅所有 topic

## Client

`Client` 是远端连接的代理类，扩展自 `@hile/message-ws`。

```typescript
import { Client } from '@hile/micro';

const result = await client.request('/api', { key: 'value' }, {
  timeout: 5000,
  signal: abortController.signal,
});

client.push('/log', { event: 'click' }); // 单向消息

const stream = client.stream('/large-data', { query: '...' }); // 流式

client.dispose(); // 停止心跳并关闭 WebSocket
```

### 心跳保活

Client 自动发送心跳，可由环境变量控制：

| 环境变量 | 默认值 | 说明 |
|-----------|--------|------|
| `MICRO_HEARTBEAT_INTERVAL` | `10000` (10s) | 心跳发送间隔 |
| `MICRO_HEARTBEAT_TIMEOUT` | `20000` (20s) | 超过此时间未收到心跳判定为超时 |
| `MICRO_HEARTBEAT_CHECK_INTERVAL` | `5000` (5s) | 超时检查间隔 |

## Registry 重连

Application 与 Registry 断开连接时自动重连：

1. 检测到 `disconnect` 事件
2. 立即尝试重新连接
3. 连接失败 → 3 秒后重试
4. `listen()` 返回的 teardown 被调用后停止重连

## 完整示例

```typescript
import { Registry, Application } from '@hile/micro';

// 启动 Registry
const registry = new Registry({ advertiseHost: '127.0.0.1' });
const closeRegistry = await registry.listen(9000);

// 启动 Provider
const provider = new Application({
  namespace: 'payments',
  registry: { host: '127.0.0.1', port: 9000 },
  advertiseHost: '127.0.0.1',
});
const closeProvider = await provider.listen(9100);

provider.register('/charge', async ({ data }) => {
  return { charged: true, amount: data.amount };
});

// 启动 Consumer（另一个进程）
const consumer = new Application({
  namespace: 'checkout',
  registry: { host: '127.0.0.1', port: 9000 },
  advertiseHost: '127.0.0.1',
});
const closeConsumer = await consumer.listen(9200);

// 远程调用
const result = await consumer.call('payments', '/charge', { amount: 100 });
console.log(result); // { charged: true, amount: 100 }

// 清理
await closeConsumer();
await closeProvider();
await closeRegistry();
```

## 与 @hile/core 的关系

`@hile/micro` **不依赖** `@hile/core`，可与任意 Node.js 进程独立使用。
