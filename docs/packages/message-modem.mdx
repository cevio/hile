## 概述

`MessageModem` 是一个**抽象基类**，将底层传输（WebSocket、postMessage、IPC、Worker 等）与请求/响应协议解耦。

子类只需实现两个抽象方法：

| 方法 | 职责 |
|------|------|
| `post(data)` | 将消息发送到远端 |
| `exec(data, signal)` | 处理收到的请求，返回响应数据 |

框架自动处理：

- **请求/响应配对** — 自增 ID + Promise 栈
- **超时控制** — 默认 30 秒，可覆盖
- **主动中止** — 发送方 `AbortSignal` → 接收方 `AbortController.abort()`
- **错误传播** — `Exception` 携带 status 码透传；普通 `Error` 映射为 500
- **流式传输** — `_stream()` 返回 `Readable`，远端 `AsyncIterable` 逐块消费

## 消息类型

| 枚举值 | 说明 |
|--------|------|
| `REQUEST` | 请求消息。`twoway: true` 为双向（期待回复），`false` 为单向 |
| `RESPONSE` | 响应消息。携带 `status` / `data` / `message` |
| `ABORT` | 中止消息。发送方取消某 ID 的请求，接收方取消对应 `exec` |

### 消息格式

```typescript
interface MessageTransferFormat<T = any> {
  id: number;               // 自增消息 ID
  mode: MESSAGE_MODEM_TYPE; // REQUEST / RESPONSE / ABORT
  twoway: boolean;          // 是否需要响应
  stream?: boolean;         // 是否为流式请求
  data?: T;                 // 消息数据
}
```

### 响应格式

```typescript
interface MessageReturnFormat<T = any> {
  status: string | number;  // 200 成功，其他为错误码
  data: T;
  message: string;
}
```

### 流式块格式

```typescript
interface MessageStreamChunk<T = any> {
  status: string | number;
  seq: number;              // 块序号
  payload: T;
  final: boolean;           // 是否为最后一个块
}
```

## 核心 API

### `MessageModem`（抽象类）

| 方法 | 可见性 | 签名 | 说明 |
|------|--------|------|------|
| `post` | `protected abstract` | `(data: MessageTransferFormat) => void` | 子类实现：如何将消息发出 |
| `exec` | `protected abstract` | `(data: any, signal?: AbortSignal) => Promise<any>` | 子类实现：处理收到的请求。返回 `Promise`（普通值）；支持 `AsyncIterable`（需配合 `_stream`） |
| `_send` | `protected` | `(data, { timeout?, signal? }) => Promise<T>` | 发送双向请求（`twoway: true`），`timeout` 默认 30000ms |
| `_push` | `protected` | `(data, { timeout?, signal? }) => void` | 发送单向消息（`twoway: false`），接收方不回复 |
| `_stream` | `protected` | `(data, { signal? }) => Readable` | 发送流式请求，返回 `Readable`（objectMode），逐块消费远端 `AsyncIterable` |
| `receive` | `public` | `(msg: MessageTransferFormat) => void` | 接收消息入口，按 `mode` 分发到 `onRequest` / `onResponse` / `onAbort` / 流式处理 |
| `_dispose` | `protected` | `() => void` | 释放所有待处理的 Promise、流和 AbortController |

### 双向请求（`_send`）

```text
发送方                           接收方
  │                                │
  │  _send(data)                   │
  │──── REQUEST (twoway:true) ────►│
  │                                │ exec(data, signal)
  │◄──── RESPONSE ─────────────────│
  │  resolve(data)                 │
  │                                │
  │  发送方 abort()                 │
  │──── ABORT ────────────────────►│
  │                                │ controller.abort() → exec 收到中止信号
```

### 单向消息（`_push`）

```text
发送方                           接收方
  │                                │
  │  _push(data)                   │
  │──── REQUEST (twoway:false) ───►│
  │                                │ exec(data)（不回复）
```

### 流式传输（`_stream`）

```text
发送方                           接收方
  │                                │
  │  _stream(data)                 │
  │──── REQUEST (stream:true) ────►│
  │                                │ exec → AsyncIterable
  │◄──── RESPONSE (stream:true) ───│  { seq:0, payload, final:false }
  │◄──── RESPONSE (stream:true) ───│  { seq:1, payload, final:false }
  │◄──── RESPONSE (stream:true) ───│  { seq:2, payload, final:true  }
  │  stream.push(chunk) ...        │
```

## 快速开始

### 最小实现

```typescript
import { MessageModem } from '@hile/message-modem';

class EchoModem extends MessageModem {
  protected post<T>(data: MessageTransferFormat<T>): void {
    // 通过底层传输发送 JSON
    transport.send(JSON.stringify(data));
  }

  protected async exec(data: any): Promise<any> {
    // 处理收到的请求
    return data;
  }
}
```

### WebSocket

```typescript
import { MessageModem, type MessageTransferFormat } from '@hile/message-modem';

class WebSocketModem extends MessageModem {
  constructor(private ws: WebSocket) {
    super();
    ws.addEventListener('message', (e) => {
      this.receive(JSON.parse(e.data));
    });
  }

  protected post<T>(data: MessageTransferFormat<T>): void {
    this.ws.send(JSON.stringify(data));
  }

  protected async exec(data: any): Promise<any> {
    return handleRequest(data);
  }

  public request<T>(data: T, options?: { timeout?: number; signal?: AbortSignal }) {
    return this._send<T>(data, options);
  }
}

// 使用
const modem = new WebSocketModem(ws);
const result = await modem.request({ action: 'getUser', id: 1 });
```

### Worker Threads

```typescript
import { parentPort, Worker } from 'node:worker_threads';
import { MessageModem } from '@hile/message-modem';

// 主线程
class WorkerModem extends MessageModem {
  constructor(private worker: Worker) {
    super();
    worker.on('message', (msg) => this.receive(msg));
  }

  protected post<T>(data: MessageTransferFormat<T>): void {
    this.worker.postMessage(data);
  }

  protected async exec(data: any): Promise<any> {
    return handleRequest(data);
  }

  public request<T>(data: T, options?: { timeout?: number; signal?: AbortSignal }) {
    return this._send<T>(data, options);
  }
}

// Worker 线程
class ParentModem extends MessageModem {
  constructor() {
    super();
    parentPort!.on('message', (msg) => this.receive(msg));
  }

  protected post<T>(data: MessageTransferFormat<T>): void {
    parentPort!.postMessage(data);
  }

  protected async exec(data: any): Promise<any> {
    return heavyComputation(data);
  }
}
```

## 异常处理

| 类 | `status` | 默认 `message` | 触发时机 |
|------|----------|------|------|
| `Exception` | 自定义 | 自定义 | `exec` 中主动抛出，status 码透传到发送方 |
| `TimeoutException` | `ETIMEDOUT` | `Timeout` | 超过指定超时时间（默认 30s） |
| `AbortException` | `ECONNABORTED` | `Abort` | 发送方 `signal.abort()` 或被远端 ABORT |

```typescript
// exec 中抛出错误
protected async exec(data: any): Promise<any> {
  if (!data.token) {
    throw new Exception(401, 'Unauthorized');
  }
  throw new Error('Something went wrong'); // 映射为 status 500
}

// 发送方捕获
try {
  const result = await modem.request(data);
} catch (e) {
  if (e instanceof AbortException) {
    console.log('请求被中止');
  } else if (e instanceof Exception) {
    console.log(`错误 [${e.status}]: ${e.message}`);
  }
}
```

## 流式传输示例

接收方 `exec` 返回 `AsyncIterable`，发送方通过 `_stream` 消费：

```typescript
// 接收方（Provider）
class ProviderModem extends MessageModem {
  // ...
  protected async exec(data: any): Promise<any> {
    // 返回异步迭代器
    return async function* () {
      yield { id: 1, name: 'Alice' };
      yield { id: 2, name: 'Bob' };
      yield { id: 3, name: 'Charlie' };
    }();
  }
}

// 发送方（Consumer）
class ConsumerModem extends MessageModem {
  // ...
  public query<T>(data: T, options?: { signal?: AbortSignal }) {
    return this._stream(data, options);
  }
}

const stream = modem.query({ query: 'SELECT * FROM users' });
for await (const chunk of stream) {
  console.log(chunk); // 逐块到达
}
```

## 注意事项

<Warning>
  `post` 应保持同步。如果底层传输是异步的，需在 `post` 内部缓冲，不可将 `post` 声明为 `async`——框架假设 `post` 调用后消息即发出。
</Warning>

<Warning>
  `_send`、`_push`、`_stream` 均为 `protected`。子类应自行决定如何暴露给外部调用，不应直接改为 `public`。
</Warning>

<Note>
  消息 ID 在实例内自增，两端各自维护独立的 ID 序列，互不冲突。超过 `Number.MAX_SAFE_INTEGER` 时自动归零。
</Note>
