## 安装

```bash
pnpm add @hile/http
```

## 快速开始

```typescript
import { Http } from '@hile/http'

const http = new Http({ port: 3000 })

http.get('/hello', async (ctx) => {
  ctx.body = { message: 'Hello, World!' }
})

const close = await http.listen(() => {
  console.log('Server running on http://localhost:3000')
})

// 需要时关闭服务
// close()
```

## 创建实例

```typescript
const http = new Http({
  port: 3000,                       // 必填：监听端口
  keys: ['secret1', 'secret2'],     // 可选：Koa 签名密钥（不传则自动生成随机密钥）
  ignoreDuplicateSlashes: true,     // 可选：忽略重复斜杠（默认 true）
  ignoreTrailingSlash: true,        // 可选：忽略尾部斜杠（默认 true）
  maxParamLength: Infinity,         // 可选：参数最大长度（默认 Infinity）
  allowUnsafeRegex: true,           // 可选：允许不安全正则（默认 true）
  caseSensitive: true,              // 可选：区分大小写（默认 true）
})
```

`HttpProps` 包含 `port`、`keys`，其余属性继承自 `find-my-way` 的 `Config`（排除 `defaultRoute`）。如果不传 `keys`，会自动生成两个随机密钥（`randomBytes(32)` 和 `randomBytes(64)`），用于 Koa 的 cookie 签名。

## 全局中间件

中间件按注册顺序执行，支持链式调用：

```typescript
http.use(async (ctx, next) => {
  const start = Date.now()
  await next()
  const ms = Date.now() - start
  console.log(`${ctx.method} ${ctx.url} ${ctx.status} - ${ms}ms`)
})

http.use(async (ctx, next) => {
  const start = Date.now()
  await next()
  ctx.set('X-Response-Time', `${Date.now() - ms}ms`)
})
```

`use()` 返回 `this`，支持链式调用。中间件是标准的 Koa 中间件，签名为 `(ctx, next) => Promise<void>`。

## 手动路由注册

### 快捷方法

```typescript
http.get('/users', async (ctx) => { ctx.body = [{ id: 1 }] })
http.post('/users', async (ctx) => { ctx.body = { created: true } })
http.get('/users/:id', async (ctx) => { ctx.body = { id: ctx.params.id } })
http.put('/users/:id', async (ctx) => { ctx.body = { updated: true } })
http.delete('/users/:id', async (ctx) => { ctx.body = { deleted: true } })
```

支持的快捷方法：`get`、`post`、`put`、`delete`、`trace`、`patch`。每个方法都返回注销函数。

### 路由级中间件

```typescript
const auth = async (ctx, next) => {
  if (!ctx.headers.authorization) ctx.throw(401)
  await next()
}

http.post('/users', auth, async (ctx) => {
  ctx.body = { created: true }
})
```

### 注销路由

```typescript
const off = http.get('/temporary', async (ctx) => {
  ctx.body = 'This route will be removed'
})

off() // 注销路由
```

### 任意 HTTP 方法

```typescript
http.route('PATCH', '/users/:id', async (ctx) => {
  ctx.body = { patched: true }
})
```

`route(method, url, ...middlewares)` 是通用注册方法，返回注销函数。

## 启动与关闭

```typescript
const close = await http.listen((server) => {
  // server 是 Node.js 原生 http.Server
  // 回调在端口绑定之前、createServer 之后执行
  // 适合传递 server 给其他库（如 Next.js）
  console.log(`Listening on port ${http.port}`)
})

// 关闭服务
close()
```

`listen()` 的执行流程：
1. 将路由注册到 Koa（`this.koa.use(this.router.routes())`）
2. 创建 `http.Server`（`createServer(this.koa.callback())`）
3. 执行 `onListen(server)` 回调（如果有）
4. 绑定端口
5. 返回关闭函数

## 文件系统路由

通过 `Loader` 类从目录自动加载控制器文件，文件路径即路由路径。`Http.load()` 是对 `Loader.from()` 的便捷封装。

### 定义控制器

控制器文件使用 `defineController` 定义，必须通过 `export default` 导出：

```typescript
// src/controllers/hello.controller.ts
import { defineController } from '@hile/http'

export default defineController('GET', async (ctx) => {
  return { message: 'Hello!' }
})
```

控制器返回值经过响应插件链处理后自动赋值给 `ctx.body`。控制器函数签名为 `(ctx)`，无需调用 `next()`。

### 带中间件的控制器

```typescript
import { defineController } from '@hile/http'

const auth = async (ctx, next) => {
  if (!ctx.headers.authorization) ctx.throw(401)
  await next()
}

// 中间件数组，按顺序执行
export default defineController('POST', [auth], async (ctx) => {
  return { created: true }
})
```

### 同文件多控制器

```typescript
import { defineController } from '@hile/http'

const getUsers = defineController('GET', async (ctx) => ({ users: [] }))
const createUser = defineController('POST', [auth], async (ctx) => ({ created: true }))

export default [getUsers, createUser]
```

### 使用 Zod 校验 query / params / body（可选）

`createControllerMetadata` 可构造包含 method、middlewares 和可选 Zod schema 的元数据。配合 `defineController(metadata, fn)` 注册，在进入业务 handler 前对已声明的字段执行 `safeParse`，失败则 `ctx.throw(400, message)`。

```typescript
import { z } from "zod";
import { createControllerMetadata, defineController } from "@hile/http";

export default defineController(
  createControllerMetadata({
    method: "POST",
    middlewares: [],
    schema: {
      query: z.object({ page: z.coerce.number().optional() }),
      params: z.object({ id: z.string().uuid() }),
      body: z.object({ title: z.string().min(1) }),
    },
  }),
  async (ctx) => ({
    id: ctx.params.id,
    title: ctx.request.body.title,
    page: ctx.query.page,
  }),
);
```

传统 `defineController(method, fn)` 和 `defineController(method, [mw], fn)` 不执行 Zod 校验，内部使用占位空 schema。

`defineController` 有三个重载：
- `(method, fn)` — 无校验
- `(method, [mw], fn)` — 无校验，带路由中间件
- `(metadata, fn)` — 含 Zod 校验

### 加载路由

```typescript
const off = await http.load('./src/controllers', {
  suffix: 'controller',       // 匹配 *.controller.{ts,js,tsx,jsx}
  prefix: '/api',             // 路由前缀
  defaultSuffix: '/index',    // 默认后缀（index.controller.ts → /api）
  conflict: 'warn',           // 冲突策略：error / warn / override
  onConflict: (ctx) => {      // 冲突回调
    console.warn(`路由冲突: ${ctx.routeKey}`)
  },
})

// 需要时注销所有加载的路由
// off()
```

`load()` 是异步的，使用 `@hile/loader` 扫描目录下所有 `*.controller.{ts,js,tsx,jsx}` 文件。

### 路径映射规则

假设 `prefix: '/api'`，`suffix: 'controller'`，`defaultSuffix: '/index'`：

| 文件路径 | 路由路径 | 说明 |
|---------|---------|------|
| `index.controller.ts` | `/api` | `index` 被 defaultSuffix 规则移除 |
| `hello.controller.ts` | `/api/hello` | 直接映射 |
| `users/index.controller.ts` | `/api/users` | 目录下的 index |
| `users/list.controller.ts` | `/api/users/list` | 嵌套路径 |
| `users/[id].controller.ts` | `/api/users/:id` | `[param]` → `:param` |
| `[category]/[id].controller.ts` | `/api/:category/:id` | 多层动态参数 |

### 冲突策略

| 策略 | 值 | 行为 |
|------|---|------|
| 抛错 | `'error'` | 抛出 `route conflict: GET:/api/users` 错误（默认） |
| 警告 | `'warn'` | 保留旧路由，输出警告 |
| 覆盖 | `'override'` | 用新路由替换旧路由 |

onConflict 回调上下文：
```typescript
interface LoaderConflictContext {
  routeKey: string;      // 如 "GET:/api/users"
  method: string;        // 如 "GET"
  url: string;           // 如 "/api/users"
  strategy: 'error' | 'warn' | 'override';
  resolution: 'error' | 'keep' | 'override';
}
```

## 响应插件

响应插件统一处理控制器的返回值，避免在每个控制器里重复包装。

### 注册插件

```typescript
import { defineResponsePlugin } from '@hile/http'

defineResponsePlugin(async (ctx, result, next) => {
  return await next({
    code: 0,
    message: 'success',
    data: result,
  })
})
```

处理后返回：
```json
{ "code": 0, "message": "success", "data": { /* 控制器返回值 */ } }
```

### 多个插件

插件按注册顺序串行执行，采用 onion 模型（后注册的在外层），每层必须调用 `next(transformedResult)` 传递结果：

```typescript
defineResponsePlugin(async (ctx, result, next) => {
  // 添加时间戳
  return await next({ ...result, timestamp: Date.now() })
})

defineResponsePlugin(async (ctx, result, next) => {
  // 统一包裹
  return await next({ code: 0, data: result })
})

// 最终输出：{ code: 0, data: { message: "hello", timestamp: 1711234567890 } }
```

<Warning>
  插件必须调用 `next(transformedResult)` 传递结果。如果 `next(undefined)`，`ctx.body` 不会被设置。
</Warning>

## API 参考

### Http

| 属性/方法 | 返回值 | 说明 |
|----------|--------|------|
| `new Http(props)` | `Http` | 创建实例 |
| `port` | `number` | 获取端口号 |
| `use(middleware)` | `Http` | 注册中间件，支持链式调用 |
| `listen(onListen?)` | `Promise<() => void>` | 启动服务，返回关闭函数 |
| `get(url, ...mw)` | `() => void` | 注册 GET 路由，返回注销函数 |
| `post(url, ...mw)` | `() => void` | 注册 POST 路由 |
| `put(url, ...mw)` | `() => void` | 注册 PUT 路由 |
| `delete(url, ...mw)` | `() => void` | 注册 DELETE 路由 |
| `trace(url, ...mw)` | `() => void` | 注册 TRACE 路由 |
| `patch(url, ...mw)` | `() => void` | 注册 PATCH 路由 |
| `route(method, url, ...mw)` | `() => void` | 注册任意方法路由 |
| `load(dir, options?)` | `Promise<() => void>` | 加载文件系统路由 |

### HttpProps

| 属性 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `port` | `number` | 是 | — | 监听端口 |
| `keys` | `string[]` | 否 | 随机生成 | Koa 签名密钥 |
| `ignoreDuplicateSlashes` | `boolean` | 否 | `true` | 忽略重复斜杠 |
| `ignoreTrailingSlash` | `boolean` | 否 | `true` | 忽略尾部斜杠 |
| `maxParamLength` | `number` | 否 | `Infinity` | 参数最大长度 |
| `allowUnsafeRegex` | `boolean` | 否 | `true` | 允许不安全正则 |
| `caseSensitive` | `boolean` | 否 | `true` | 路由区分大小写 |

### LoaderFromOptions

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `suffix` | `string` | `'controller'` | 文件后缀标记 |
| `prefix` | `string` | — | 路由前缀 |
| `defaultSuffix` | `string` | `'/index'` | 默认后缀 |
| `conflict` | `'error' \| 'warn' \| 'override'` | `'error'` | 冲突策略 |
| `onConflict` | `function` | — | 冲突回调 |

### 导出一览

| 导出 | 说明 |
|------|------|
| `Http` | HTTP 服务类 |
| `defineController` | 控制器定义（三种重载：method+fn / method+mw+fn / metadata+fn） |
| `createControllerMetadata` | 构造控制器元数据（method / middlewares / schema） |
| `defineResponsePlugin` | 响应插件定义函数 |
| `Loader` | 路由加载器类。`from(directory, options)` 批量加载文件路由；`compile(path, controllers, options)` 编程式注册 |
| `compileRoutePath` | 路径编译纯函数（文件路径 → 路由路径）。从 `@hile/loader` 导出 |
| `toRouterPath` | `[param]` → `:param` 转换函数。从 `@hile/loader` 导出 |
