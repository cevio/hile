# 快速开始

本教程将从零开始，教你创建并运行第一个 Hile 项目。

## 前置要求

在开始之前，请确保你已经安装了以下工具：

| 工具 | 最低版本 | 说明 |
|------|----------|------|
| **Node.js** | 20.12+ | 需要原生 `process.loadEnvFile` 支持 |
| **pnpm** | 8+ | Hile 项目使用 pnpm workspace |

<Note>
Hile 要求项目启用 **ESM**（ES Module），即在 `package.json` 中设置 `"type": "module"`。这是 Node.js 的模块系统设置，意味着你可以使用 `import/export` 语法，而不是 `require()`。
</Note>

## 方式一：使用脚手架（推荐）

脚手架是最快的方式，适合第一次接触 Hile 的开发者。

### 第 1 步：创建项目

打开终端，运行：

```bash
npx create-hile create my-first-app
```

运行后会看到交互式界面，选择模板和是否安装依赖。

**内置 6 种模板**：

| 模板名 | 说明 |
|--------|------|
| `default` | 默认模板，适合纯 API 服务 |
| `next` | Next.js 全栈模板 |
| `micro-http` | Micro + HTTP 模板 |
| `micro` | Micro 独立服务模板 |
| `micro-http-next` | Next.js + Micro + HTTP 全栈微服务模板 |
| `monorepo` | Monorepo 模板（Lerna + pnpm workspace） |

选择**默认模板**即可开始。

### 第 2 步：查看项目结构

```bash
cd my-first-app
```

默认模板的项目结构：

```
my-first-app/
├── src/
│   ├── controllers/
│   │   └── index.controller.ts     # 默认 API 控制器
│   └── services/
│       └── index.boot.ts            # 服务启动入口
├── .env                             # 环境变量文件
├── .gitignore
├── package.json
└── tsconfig.json
```

关键文件说明：

| 文件 | 作用 |
|------|------|
| `src/services/index.boot.ts` | **服务入口文件**。CLI 启动时自动扫描并加载所有 `*.boot.ts` 文件。 |
| `src/controllers/index.controller.ts` | **API 控制器**。定义 HTTP 路由处理器。 |

### 第 3 步：启动开发服务器

```bash
pnpm run dev
```

你会看到类似输出：

```
[hile] service(http-server) init
[hile] service(http-server) ready (15ms)
```

`hile start --dev` 做了什么：

1. 设置 `NODE_ENV=development`
2. 使用 `tsx` 直接运行 TypeScript 文件（无需预先编译）
3. 订阅容器事件并以彩色日志输出（`[hile]` 开头的行）
4. 扫描 `src/` 目录下所有 `*.boot.ts` 文件
5. 加载 boot 文件并启动所有服务
6. 注册退出钩子（Ctrl+C 时优雅关闭）

### 第 4 步：测试 API

```bash
curl http://localhost:3000/
```

你会看到 JSON 响应：

```json
{"message":"Hello Hile"}
```

### 第 5 步：理解启动流程

看一下 `src/services/index.boot.ts` 中的代码：

```typescript
// src/services/index.boot.ts
import { defineService } from '@hile/core'
import { Http } from '@hile/http'

// defineService 将 HTTP 服务注册到全局容器中
// 第一个参数 'http-server' 是这个服务的唯一标识（key）
// 第二个参数是工厂函数，接收 shutdown 用于注册关闭回调
export default defineService('http-server', async (shutdown) => {
  // 1. 创建 HTTP 服务实例，监听 3000 端口
  const http = new Http({ port: 3000 })

  // 2. 加载控制器路由（扫描 src/controllers/ 目录）
  await http.load('./src/controllers', {
    suffix: 'controller',      // 匹配 *.controller.ts 文件
    prefix: '/',               // URL 前缀
    defaultSuffix: '/index',   // index.controller.ts → /
  })

  // 3. 启动 HTTP 服务，listen 返回关闭函数
  const close = await http.listen()

  // 4. 注册关闭回调：容器关闭时自动调用 close()
  shutdown(close)

  // 5. 返回 HTTP 实例
  return http
})
```

**执行流程**：

```
1. CLI 执行 hile start --dev
2. → 扫描 src/**/*.boot.ts
3. → 加载该文件，获取 default export
4. → 调用 loadService(props)，执行工厂函数
5. → new Http({ port: 3000 })（此时还未监听端口）
6. → http.load() 扫描控制器目录
7. → http.listen() 启动 HTTP 服务（开始监听端口）
8. → shutdown(close) 注册关闭回调
9. → 服务就绪，等待请求
```

<Warning>
**重要概念**：`defineService` 只是"注册"服务，不会立即执行工厂函数。真正执行工厂函数的是 `loadService`。CLI 在扫描到 boot 文件后会自动调用 `loadService`。
</Warning>

## 方式二：手动搭建项目

如果你想更深入地理解 Hile 的工作原理，可以手动搭建项目。

### 第 1 步：初始化项目

```bash
mkdir my-handmade-api && cd my-handmade-api
pnpm init
```

编辑 `package.json`，添加 `"type": "module"` 和脚本：

```json
{
  "name": "my-handmade-api",
  "type": "module",
  "scripts": {
    "dev": "hile start --dev",
    "build": "tsc -b",
    "start": "hile start"
  }
}
```

### 第 2 步：安装依赖

```bash
pnpm add @hile/core @hile/http @hile/cli
```

三个包各自的职责：
- `@hile/core`：**服务容器**。管理服务的创建、缓存、依赖追踪和优雅关闭。
- `@hile/http`：**HTTP 框架**。基于 Koa + find-my-way，提供路由、中间件、控制器。
- `@hile/cli`：**命令行启动器**。提供 `hile start` 命令，自动扫描 boot 文件。

### 第 3 步：创建 tsconfig.json

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "outDir": "./dist",
    "rootDir": "./src",
    "declaration": true
  },
  "include": ["src"],
  "exclude": ["node_modules", "dist"]
}
```

### 第 4 步：创建目录结构

```bash
mkdir -p src/services src/controllers
```

### 第 5 步：创建 HTTP 服务

在 `src/services/http.boot.ts` 中：

```typescript
// src/services/http.boot.ts
import { defineService } from '@hile/core'
import { Http } from '@hile/http'

export default defineService('http-server', async (shutdown) => {
  const http = new Http({
    port: 3000,
    ignoreDuplicateSlashes: true,
    ignoreTrailingSlash: true,
    maxParamLength: 100,
  })

  // 注册全局中间件（Koa 中间件）
  http.use(async (ctx, next) => {
    const start = Date.now()
    await next()
    const ms = Date.now() - start
    console.log(`${ctx.method} ${ctx.url} - ${ms}ms`)
  })

  // 手动注册路由
  http.get('/manual', async (ctx) => {
    ctx.body = { message: '手动注册的路由' }
  })

  // 从文件系统加载路由
  await http.load('./src/controllers', {
    suffix: 'controller',
    prefix: '/api',
    defaultSuffix: '/index',
  })

  const close = await http.listen()
  shutdown(close)

  console.log(`Server running on http://localhost:${http.port}`)
  return http
})
```

### 第 6 步：创建控制器

`src/controllers/hello.controller.ts`：

```typescript
import { defineController } from '@hile/http'

// 这个文件自动映射为 GET /api/hello
export default defineController('GET', async (ctx) => {
  return {
    message: 'Hello, Hile!',
    url: ctx.url,
    method: ctx.method,
    timestamp: Date.now(),
  }
})
```

**带 Zod 校验的控制器**：`src/controllers/greeting.controller.ts`：

```typescript
import { defineController, createControllerMetadata } from '@hile/http'
import { z } from 'zod'

export default defineController(
  createControllerMetadata({
    method: 'GET',
    schema: {
      query: z.object({
        name: z.string().min(1).max(50).default('World'),
        repeat: z.coerce.number().min(1).max(10).default(1),
      }),
    },
  }),
  async (ctx) => {
    const greetings = Array.from(
      { length: ctx.query.repeat },
      (_, i) => `${i + 1}: Hello ${ctx.query.name}!`
    )
    return { greetings, count: greetings.length }
  }
)
```

### 第 7 步：启动并测试

```bash
pnpm run dev
```

测试路由：

```bash
# 手动注册的路由
curl http://localhost:3000/manual
# → {"message":"手动注册的路由"}

# 文件系统路由（带 prefix /api）
curl http://localhost:3000/api/hello
# → {"message":"Hello, Hile!","url":"/api/hello","method":"GET","timestamp":...}

# 带查询参数 + Zod 校验
curl "http://localhost:3000/api/greeting?name=Hile&repeat=3"
# → {"greetings":["1: Hello Hile!","2: Hello Hile!","3: Hello Hile!"],"count":3}
```

### 第 8 步：理解优雅关闭

按 `Ctrl+C` 停止服务器，你会看到：

```
^C
[hile] service(http-server) stopping
[hile] service(http-server) stopped (3ms)
[hile] container shutdown start
[hile] container shutdown done (5ms)
```

这就是 Hile 的**优雅关闭**机制：CLI 通过 `async-exit-hook` 捕获 SIGINT/SIGTERM 信号，调用 `container.shutdown()`，按 LIFO 顺序执行每个服务的 shutdown 回调。

## 文件路由映射规则

Hile 将文件路径自动转换为 URL 路由：

| 文件路径 | 路由路径（prefix: /api） |
|----------|--------------------------|
| `hello.controller.ts` | `/api/hello` |
| `users/index.controller.ts` | `/api/users`（index → 父路径） |
| `users/[id].controller.ts` | `/api/users/:id`（[param] → :param） |
| `users/[id]/posts.controller.ts` | `/api/users/:id/posts` |

## 常见问题

<Accordion title="为什么启动后访问路由返回 404？">
可能的原因：

1. **控制器文件后缀不正确**：文件名必须以 `.controller.ts` 结尾
2. **控制器文件需要 default export**：`export default defineController(...)`，命名导出不会被加载
3. **路由前缀不匹配**：如果设置了 `prefix: '/api'`，需访问 `/api/xxx`

</Accordion>

<Accordion title="修改控制器后没有生效？">
纯 API 项目没有热重载功能。需要按 `Ctrl+C` 停止后重新运行 `pnpm run dev`。
</Accordion>

<Accordion title="如何在一个控制器文件中定义多个路由？">
导出数组即可：

```typescript
const getUsers = defineController('GET', async (ctx) => { ... })
const createUser = defineController('POST', async (ctx) => { ... })
export default [getUsers, createUser]
```
</Accordion>

<Accordion title="如何在控制器中获取请求体？">
Hile 基于 Koa，默认没有 body parser。需要添加中间件：

```typescript
import bodyParser from 'koa-bodyparser'
http.use(bodyParser())
```

然后在控制器中通过 `ctx.request.body` 获取。
</Accordion>
