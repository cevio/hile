## 前置要求

- **Node.js** >= 20.12（需要原生 `process.loadEnvFile` 支持）
- **pnpm**（推荐）或 npm/yarn
- **TypeScript** 5+

## 方式一：使用脚手架（推荐）

最快的上手方式是使用 `create-hile` 脚手架：按提示**选择内置模板**（默认、Next.js、Micro 相关等），复制完整项目结构。下文以带 **Next.js + `http-next`** 的模板为例说明目录与 `/-/post` 验证步骤；其他模板请以生成后的 `package.json` 与 README 为准。

<Steps>
  <Step title="创建项目">
    在终端中运行：

    ```bash
    npx create-hile create my-app
    ```

    脚手架会：
    - 交互选择模板并复制完整项目结构
    - 将模板中的 `_env` / `_env.prod` / `_gitignore` 重命名为 `.env` / `.env.prod` / `.gitignore`（若存在）
    - 自动将 `package.json` 的 `name` 设为你指定的项目名
    - 输出后续操作提示
  </Step>
  <Step title="安装依赖">
    ```bash
    cd my-app
    pnpm install
    ```
  </Step>
  <Step title="启动开发服务器">
    ```bash
    pnpm run dev
    ```

    这条命令会：
    1. 执行 `hile start --dev` 以开发模式启动服务
    2. 自动设置 `NODE_ENV=development`
    3. 使用 `tsx` 运行 TypeScript（无需预编译）
    4. Next.js 在 `HttpNext.start()` 内以 dev 模式自动运行，支持 HMR

    浏览器打开 `http://localhost:3000` 即可看到页面。
  </Step>
  <Step title="验证 API 路由">
    示例 API 控制器在 **`src/controllers/post.controller.ts`**（`HttpNext` 默认从 **`src/controllers/`** 加载）。访问：

    ```bash
    curl http://localhost:3000/-/post
    ```

    你会看到 JSON 响应：

    ```json
    {
      "id": 1,
      "title": "Hile Http Next Demo",
      "url": "/-/post",
      "content": "基于 Koa + find-my-way 的 HTTP 服务框架..."
    }
    ```

    注意 API 路由的前缀是 `/-`，这是与 Next.js 页面路由隔离的约定。
  </Step>
</Steps>

### 生成的项目结构

以下树形结构以选择 **`next`**（或等价的带 Next.js + `http-next` 全栈）模板为准；其他模板目录与启动脚本可能不同。

```
my-app/
├── public/                    # 静态资源（图片、字体等）
│   ├── next.svg
│   └── vercel.svg
├── src/
│   ├── app/                   # Next.js App Router
│   │   ├── layout.tsx         # 根布局（HTML 骨架）
│   │   ├── page.tsx           # 首页组件
│   │   ├── page.module.css    # 首页样式
│   │   ├── globals.css        # 全局 CSS
│   │   └── click.tsx          # Client 组件示例
│   ├── controllers/
│   │   └── post.controller.ts # API 示例 → GET /-/post
│   ├── models/
│   │   ├── home/
│   │   │   └── home.model.ts    # 首页 defineModel（export default）
│   │   └── post/
│   │       └── post.model.ts    # /-/post defineModel（export default）
│   └── services/
│       └── index.boot.ts      # Hile 服务启动入口（*.boot.ts 须在 src/ 下）
├── next.config.ts             # Next.js 配置
├── tsconfig.json              # TypeScript 配置（Node.js 代码）
├── tsconfig.next.json         # TypeScript 配置（Next.js）
├── eslint.config.mjs          # ESLint 配置
└── package.json
```

关键文件说明：

- **`src/services/index.boot.ts`**：Hile 服务入口。CLI 会自动扫描并加载 `*.boot.{ts,js}` 文件（递归搜索 `src/` 目录，通常约定放在 `src/services/`）。创建 **`HttpNext`** 并 **`start()`**；默认 API 根为 **`src/controllers/`**。
- **`src/models/<领域>/*.model.ts`**：业务数据，**`export default defineModel`**；示例 **`home/home.model.ts`**、**`post/post.model.ts`**。
- **`src/controllers/post.controller.ts`**：API 示例（**`GET /-/post`**），内 **`loadModel`** + **default** **import**。
- **`src/app/page.tsx`**：首页 SSR，示范 **`loadModel`** + **`export const dynamic = "force-dynamic"`**（凡 **`page.tsx`** 使用 **`loadModel`** 时需要）。

## 方式二：手动搭建纯 API 项目

如果你不需要 Next.js SSR，可以手动搭建一个纯 API 项目。

<Steps>
  <Step title="初始化项目">
    ```bash
    mkdir my-api && cd my-api
    pnpm init
    ```

    编辑 `package.json`，添加 `"type": "module"`：

    ```json
    {
      "name": "my-api",
      "type": "module",
      "scripts": {
        "dev": "hile start --dev",
        "build": "tsc -b",
        "start": "hile start"
      }
    }
    ```
  </Step>
  <Step title="安装依赖">
    ```bash
    pnpm add @hile/core @hile/http @hile/cli
    ```
  </Step>
  <Step title="创建 tsconfig.json">
    ```json
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "ESNext",
        "moduleResolution": "bundler",
        "strict": true,
        "esModuleInterop": true,
        "skipLibCheck": true,
        "outDir": "./dist",
        "rootDir": "./src",
        "declaration": true
      },
      "include": ["src"],
      "exclude": ["node_modules", "dist"]
    }
    ```
  </Step>
  <Step title="创建服务入口">
    创建 `src/services/http.boot.ts`（`*.boot.ts` 文件会被 CLI 自动加载）：

    ```typescript
    import { defineService } from '@hile/core'
    import { Http } from '@hile/http'

    export default defineService('http', async (shutdown) => {
      const http = new Http({ port: 3000 })

      // 注册全局中间件：请求日志
      http.use(async (ctx, next) => {
        const start = Date.now()
        await next()
        const ms = Date.now() - start
        console.log(`${ctx.method} ${ctx.url} - ${ms}ms`)
      })

      // 加载文件系统路由
      await http.load('./src/controllers', {
        suffix: 'controller',
        prefix: '/api',
        defaultSuffix: '/index',
      })

      const close = await http.listen()
      shutdown(close) // 注册关闭回调

      console.log(`Server running on http://localhost:${http.port}`)
      return http
    })
    ```
  </Step>
  <Step title="创建控制器">
    创建 `src/controllers/hello.controller.ts`：

    ```typescript
    import { defineController } from '@hile/http'

    export default defineController('GET', async (ctx) => {
      return {
        message: 'Hello, Hile!',
        timestamp: Date.now(),
      }
    })
    ```

    这个文件会被自动映射到 `GET /api/hello`。
  </Step>
  <Step title="启动服务">
    ```bash
    pnpm run dev
    ```

    测试：

    ```bash
    curl http://localhost:3000/api/hello
    # {"message":"Hello, Hile!","timestamp":1711234567890}
    ```
  </Step>
</Steps>

### 添加更多控制器

创建 `src/controllers/users/index.controller.ts`：

```typescript
import { defineController } from '@hile/http'

const getUsers = defineController('GET', async (ctx) => {
  return { users: [{ id: 1, name: 'Alice' }, { id: 2, name: 'Bob' }] }
})

const createUser = defineController('POST', async (ctx) => {
  return { created: true }
})

// 同一文件导出多个控制器
export default [getUsers, createUser]
```

路径映射结果：
- `GET /api/users` → getUsers
- `POST /api/users` → createUser

## 方式三：添加数据库和缓存

在已有项目中追加 TypeORM 和 ioredis 集成：

<Steps>
  <Step title="安装集成包">
    ```bash
    pnpm add @hile/typeorm @hile/ioredis
    ```
  </Step>
  <Step title="配置环境变量">
    创建 `.env` 文件：

    ```env
    TYPEORM_TYPE=mysql
    TYPEORM_HOST=localhost
    TYPEORM_PORT=3306
    TYPEORM_USERNAME=root
    TYPEORM_PASSWORD=secret
    TYPEORM_DATABASE=mydb
    TYPEORM_ENTITIES=dist/entities/*.js
    # 需要自动建表时设为 true；生产勿开启
    TYPEORM_SYNCHRONIZE=true

    REDIS_HOST=localhost
    REDIS_PORT=6379
    REDIS_DB=0
    ```
  </Step>
  <Step title="在 package.json 中配置自动加载">
    ```json
    {
      "hile": {
        "auto_load_packages": ["@hile/typeorm", "@hile/ioredis"]
      }
    }
    ```

    这样 CLI 启动时会自动初始化数据库连接和 Redis 连接。
  </Step>
  <Step title="在控制器中使用">
    ```typescript
    import { defineController } from '@hile/http'
    import { loadService } from '@hile/core'
    import typeormService from '@hile/typeorm'
    import ioredisService from '@hile/ioredis'

    export default defineController('GET', async (ctx) => {
      const db = await loadService(typeormService)
      const redis = await loadService(ioredisService)

      // 先查缓存
      const cached = await redis.get('users')
      if (cached) return JSON.parse(cached)

      // 缓存未命中，查数据库
      const users = await db.query('SELECT * FROM users LIMIT 10')
      await redis.set('users', JSON.stringify(users), 'EX', 60)
      return users
    })
    ```
  </Step>
  <Step title="启动（加载 env 文件）">
    ```bash
    hile start --dev --env-file .env
    ```
  </Step>
</Steps>

## 常用命令速查

| 命令 | 说明 |
|------|------|
| `hile start` | 生产模式启动 |
| `hile start --dev` | 开发模式（使用 tsx，扫描 src/） |
| `hile start --env-file .env` | 加载 env 文件 |
| `hile start --env-file .env --env-file .env.local` | 加载多个 env 文件 |
| `hile registry` | 启动注册中心 |
| `hile registry configs` | 管理注册中心配置 |
| `hile registry configs get <ns>` | 查看某个 namespace 的配置 |
| `hile registry configs set <ns> <key>=<value>` | 设置配置项 |
| `hile registry configs del <ns> [key]` | 删除配置 |
| `hile -v` | 查看版本 |
| `hile -h` | 查看帮助 |
