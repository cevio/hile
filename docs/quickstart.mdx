## 前置要求

- **Node.js** >= 20.12（需要原生 `process.loadEnvFile` 支持）
- **pnpm**（推荐）或 npm/yarn
- **TypeScript** 5+

## 方式一：使用脚手架（推荐）

最快的上手方式是使用 `create-hile` 脚手架，它会生成一个包含 Koa API + Next.js SSR 的完整项目。

<Steps>
  <Step title="创建项目">
    在终端中运行：

    ```bash
    npx create-hile create my-app
    ```

    脚手架会：
    - 从内置模板复制完整项目结构
    - 自动将 `package.json` 的 `name` 设为你指定的项目名
    - 输出后续操作提示
  </Step>
  <Step title="安装依赖">
    ```bash
    cd my-app
    pnpm install
    ```
  </Step>
  <Step title="启动开发服务器">
    ```bash
    pnpm run dev
    ```

    这条命令会：
    1. 执行 `next build` 构建 Next.js 应用
    2. 执行 `hile start --dev` 以开发模式启动服务
    3. 自动设置 `NODE_ENV=development`
    4. 使用 tsx 运行 TypeScript（无需预编译）

    浏览器打开 `http://localhost:3000` 即可看到页面。
  </Step>
  <Step title="验证 API 路由">
    项目自带一个示例控制器 `src/app/post.controller.ts`，访问：

    ```bash
    curl http://localhost:3000/-/post
    ```

    你会看到 JSON 响应：

    ```json
    {
      "id": 1,
      "title": "Hile Http Next Demo",
      "url": "/-/post",
      "content": "基于 Koa + find-my-way 的 HTTP 服务框架..."
    }
    ```

    注意 API 路由的前缀是 `/-`，这是与 Next.js 页面路由隔离的约定。
  </Step>
</Steps>

### 生成的项目结构

```
my-app/
├── public/                    # 静态资源（图片、字体等）
│   ├── next.svg
│   └── vercel.svg
├── src/
│   ├── app/                   # Next.js App Router + 控制器
│   │   ├── layout.tsx         # 根布局（HTML 骨架）
│   │   ├── page.tsx           # 首页组件
│   │   ├── page.module.css    # 首页样式
│   │   ├── globals.css        # 全局 CSS
│   │   ├── click.tsx          # Client 组件示例
│   │   └── post.controller.ts # API 控制器 → GET /-/post
│   └── index.boot.ts          # Hile 服务启动入口
├── next.config.ts             # Next.js 配置
├── tsconfig.json              # TypeScript 配置（Node.js 代码）
├── tsconfig.next.json         # TypeScript 配置（Next.js）
├── eslint.config.mjs          # ESLint 配置
└── package.json
```

关键文件说明：

- **`src/index.boot.ts`**：Hile 服务入口。CLI 会自动扫描并加载 `*.boot.ts` 文件。它创建 `HttpNext` 实例并调用 `start()` 启动服务。
- **`src/app/post.controller.ts`**：API 控制器示例。文件名包含 `.controller.` 后缀，会被自动识别并挂载到 `/-/post` 路由。
- **`src/app/page.tsx`**：Next.js 页面组件，处理 `/` 路由的 SSR 渲染。

## 方式二：手动搭建纯 API 项目

如果你不需要 Next.js SSR，可以手动搭建一个纯 API 项目。

<Steps>
  <Step title="初始化项目">
    ```bash
    mkdir my-api && cd my-api
    pnpm init
    ```

    编辑 `package.json`，添加 `"type": "module"`：

    ```json
    {
      "name": "my-api",
      "type": "module",
      "scripts": {
        "dev": "hile start --dev",
        "build": "tsc -b",
        "start": "hile start"
      }
    }
    ```
  </Step>
  <Step title="安装依赖">
    ```bash
    pnpm add @hile/core @hile/http @hile/cli
    ```
  </Step>
  <Step title="创建 tsconfig.json">
    ```json
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "ESNext",
        "moduleResolution": "bundler",
        "strict": true,
        "esModuleInterop": true,
        "skipLibCheck": true,
        "outDir": "./dist",
        "rootDir": "./src",
        "declaration": true
      },
      "include": ["src"],
      "exclude": ["node_modules", "dist"]
    }
    ```
  </Step>
  <Step title="创建服务入口">
    创建 `src/http.boot.ts`：

    ```typescript
    import { defineService } from '@hile/core'
    import { Http } from '@hile/http'

    export default defineService('http', async (shutdown) => {
      const http = new Http({ port: 3000 })

      // 注册全局中间件：请求日志
      http.use(async (ctx, next) => {
        const start = Date.now()
        await next()
        const ms = Date.now() - start
        console.log(`${ctx.method} ${ctx.url} - ${ms}ms`)
      })

      // 加载文件系统路由
      await http.load('./src/controllers', {
        suffix: 'controller',
        prefix: '/api',
        defaultSuffix: '/index',
      })

      const close = await http.listen()
      shutdown(close) // 注册关闭回调

      console.log(`Server running on http://localhost:${http.port}`)
      return http
    })
    ```
  </Step>
  <Step title="创建控制器">
    创建 `src/controllers/hello.controller.ts`：

    ```typescript
    import { defineController } from '@hile/http'

    export default defineController('GET', async (ctx) => {
      return {
        message: 'Hello, Hile!',
        timestamp: Date.now(),
      }
    })
    ```

    这个文件会被自动映射到 `GET /api/hello`。
  </Step>
  <Step title="启动服务">
    ```bash
    pnpm run dev
    ```

    测试：

    ```bash
    curl http://localhost:3000/api/hello
    # {"message":"Hello, Hile!","timestamp":1711234567890}
    ```
  </Step>
</Steps>

### 添加更多控制器

创建 `src/controllers/users/index.controller.ts`：

```typescript
import { defineController } from '@hile/http'

const getUsers = defineController('GET', async (ctx) => {
  return { users: [{ id: 1, name: 'Alice' }, { id: 2, name: 'Bob' }] }
})

const createUser = defineController('POST', async (ctx) => {
  return { created: true }
})

// 同一文件导出多个控制器
export default [getUsers, createUser]
```

路径映射结果：
- `GET /api/users` → getUsers
- `POST /api/users` → createUser

## 方式三：添加数据库和缓存

在已有项目中追加 TypeORM 和 ioredis 集成：

<Steps>
  <Step title="安装集成包">
    ```bash
    pnpm add @hile/typeorm @hile/ioredis
    ```
  </Step>
  <Step title="配置环境变量">
    创建 `.env` 文件：

    ```env
    TYPEORM_TYPE=mysql
    TYPEORM_HOST=localhost
    TYPEORM_PORT=3306
    TYPEORM_USERNAME=root
    TYPEORM_PASSWORD=secret
    TYPEORM_DATABASE=mydb
    TYPEORM_ENTITIES=dist/entities/*.js

    REDIS_HOST=localhost
    REDIS_PORT=6379
    REDIS_DB=0
    ```
  </Step>
  <Step title="在 package.json 中配置自动加载">
    ```json
    {
      "hile": {
        "auto_load_packages": ["@hile/typeorm", "@hile/ioredis"]
      }
    }
    ```

    这样 CLI 启动时会自动初始化数据库连接和 Redis 连接。
  </Step>
  <Step title="在控制器中使用">
    ```typescript
    import { defineController } from '@hile/http'
    import { loadService } from '@hile/core'
    import typeormService from '@hile/typeorm'
    import ioredisService from '@hile/ioredis'

    export default defineController('GET', async (ctx) => {
      const db = await loadService(typeormService)
      const redis = await loadService(ioredisService)

      // 先查缓存
      const cached = await redis.get('users')
      if (cached) return JSON.parse(cached)

      // 缓存未命中，查数据库
      const users = await db.query('SELECT * FROM users LIMIT 10')
      await redis.set('users', JSON.stringify(users), 'EX', 60)
      return users
    })
    ```
  </Step>
  <Step title="启动（加载 env 文件）">
    ```bash
    hile start --dev --env-file .env
    ```
  </Step>
</Steps>

## 生产部署

```bash
# 1. 编译 TypeScript
pnpm run build

# 2. 生产模式启动
NODE_ENV=production hile start
```

生产模式下：
- CLI 扫描 `dist/` 目录而非 `src/`
- TypeORM 关闭 SQL 日志
- 不使用 tsx，直接运行编译后的 JS

## 常用命令速查

| 命令 | 说明 |
|------|------|
| `hile start` | 生产模式启动 |
| `hile start --dev` | 开发模式（使用 tsx，扫描 src/） |
| `hile start --env-file .env` | 加载 env 文件 |
| `hile start --env-file .env --env-file .env.local` | 加载多个 env 文件 |
| `hile -v` | 查看版本 |
| `hile -h` | 查看帮助 |
